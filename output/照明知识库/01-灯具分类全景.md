# 01 灯具分类全景

> **回答的问题**：不同领域里，灯到底有哪些型式？怎么建立一套不重不漏的分类？
> **适用**：选型、竞品分析、产品线规划、与供应商对齐语言

---

## 1. 先建立「五维坐标系」

新手最容易犯的错，是只用「家用 / 商用 / 工业」一把尺子分类。实际上，任何一盏灯都同时落在五个维度上：

```
                     ┌─────────────┐
                     │  应用领域    │  办公 / 教育 / 医疗 / 商业 / 道路 / 汽车…
                     └──────┬──────┘
                            │
        ┌───────────────────┼───────────────────┐
        │                   │                   │
┌───────▼──────┐    ┌───────▼──────┐    ┌───────▼──────┐
│  安装方式     │    │  光分布      │    │  环境防护     │
│ 固定/可移/嵌入│    │ 直接/间接/配光│    │ IP/IK/防爆/防腐│
└───────┬──────┘    └───────┬──────┘    └───────┬──────┘
        │                   │                   │
        └───────────────────┼───────────────────┘
                            │
                     ┌──────▼───────┐
                     │  控制方式     │  开关 / 调光 / DALI / 无线 / 集中控制
                     └──────────────┘
```

**用法**：描述一款灯时，至少说清「场景 + 安装 + 配光 + 防护 + 控制」五件事。例如：

> 「办公场景、嵌入式安装、中宽配光、IP20、DALI-2 调光的 600×600 LED 面板灯」

这比「一个商用面板灯」精确得多，也直接对应到标准、参数和成本。

## 2. 按光源技术分（了解代际，判断存量/增量）

| 代际 | 光源类型 | 当前状态 | 典型特点 | 主要问题 |
|---|---|---|---|---|
| 第一代 | 白炽灯 | 基本退市 | 显色好、即开即亮、便宜 | 光效极低（约 10–15 lm/W）、寿命短 |
| 第二代 | 卤钨灯 | 少量特殊用途 | 体积小、光色好、可调光 | 发热大、光效仍低 |
| 第三代 | 荧光灯（T8/T5/CFL） | 存量市场，持续被替换 | 光效较高、成本低 | 含汞、频闪、低温启动差、需镇流器 |
| 第三代 | HID（金卤灯/高压钠灯） | 道路、工业、体育存量 | 高光通量、高光强 | 启动慢、显色差异大、含汞、维护成本高 |
| 第四代 | **LED** | **绝对主流** | 光效高、寿命长、可调光调色、体积小 | 热敏感、驱动依赖、品质分化极大 |
| 第四代+ | OLED | 高端装饰/汽车尾灯 | 面光源、薄、可柔性 | 亮度低、寿命/成本限制 |
| 第五代 | 激光/LD | 汽车远光、舞台、特种 | 极高亮度、定向性强 | 成本高、安全要求高 |
| 其他 | 氙灯 | 汽车、探照灯、舞台 | 高亮度、光色接近日光 | 高压、启动复杂、寿命有限 |

> **产品经理视角**：做新项目，光源基本默认 LED；但要理解荧光灯/HID 的存量替换市场——「替换-existing」往往比「全新安装」更大，且对尺寸、接口、驱动兼容性有额外约束。

## 4. 商用/办公/公共建筑的重点产品细分

这是你的主战场，单独展开。下表是「产品形态 → 典型规格 → 关键参数 → 常见坑」。

| 产品 | 典型规格/形态 | 关键参数 | 常见坑 |
|---|---|---|---|
| **LED 面板灯** | 600×600、300×600、300×1200；24–40 W；3000–4000 lm | 整灯效能、眩光（UGR）、出光均匀度、厚度、驱动内置/外置、PF | 只看瓦数不看光通量；扩散板发黄；驱动内置散热差；边框漏光 |
| **LED 筒灯** | 2/3/4/6/8 寸；7–30 W；开孔尺寸固定 | 光束角、中心光强、UGR、开孔兼容、散热、调光 | 开孔不兼容；深防眩不够；驱动与调光器不匹配导致闪烁 |
| **LED 射灯/轨道灯** | GU10/E27 替换型；一体式 COB；15–40 W | 光束角（15°/24°/36°）、中心光强、Ra/R9、色容差、调光 | 光斑不均、黄斑、副光斑；轨道适配性差 |
| **LED 线条灯** | 1.2 m/1.5 m/2 m；20–60 W；吊装/嵌入/明装 | 拼接无缝、配光（直下/偏配光）、级联长度、驱动方案 | 拼接处暗缝；首尾亮度差；级联压降 |
| **LED 格栅灯** | 600×600、600×1200；3×T5/T8 替代 | UGR、防眩格栅、可换光源、维护 | 格栅变形；光源更换困难；效率低 |
| **磁吸轨道灯** | 轨道+射灯/线条/泛光模块 | 系统兼容、安全（防触电）、功率上限、调光 | 不同品牌不兼容；轨道接头打火；磁吸力不足 |
| **LED 灯带** | 24 V/48 V；5–20 W/m；裸板/套管/硅胶 | 光效、色容差（SDCM）、压降、防水等级、显色 | 首尾色差；长距离压降；防水失效；粘贴脱落 |
| **工矿灯** | UFO 圆形/方形；50–300 W | 光效、配光角度、散热、IP65/66、IK、重量 | 散热不足导致光衰；配光与厂房高度不匹配；吊装安全 |
| **投光灯** | 10–1000 W；窄/中/宽配光 | 光强、光束角、防眩、IP66/67、防腐、支架 | 眩光严重；积水；支架锈蚀；光斑溢出 |
| **应急照明灯** | 双头灯、标志灯、集中电源 | 响应时间、持续时间、A/B 型、IP、集中控制 | 电池衰减；标志灯不持续亮；与消防系统不兼容 |
| **防爆灯** | Ex d/e、LED 一体式 | Ex 等级、温度组别、IP66、IK、材质 | 隔爆面损伤；电缆引入装置不匹配；认证造假 |

## 5. 按安装方式分（直接对应安规标准族）

| 安装方式 | 定义要点 | 典型产品 | 对应标准族（IEC / GB/T 7000 系列） |
|---|---|---|---|
| **固定式** | 只能借助工具拆卸，或安装在不易接触处 | 吸顶灯、壁灯、路灯、工矿灯 | IEC 60598-2-1 / GB/T 7000.201 系列 |
| **可移式** | 正常使用时可从一处移到另一处 | 台灯、落地灯、夹灯 | IEC 60598-2-4 / GB/T 7000.204 系列 |
| **嵌入式** | 完全或部分嵌入安装表面 | 筒灯、格栅灯、嵌入线条灯 | IEC 60598-2-2 / GB/T 7000.202 系列 |
| **地面嵌入式** | 嵌入地面，可承压/防水 | 地埋灯、地面引导灯 | IEC 60598-2-13 / GB/T 7000.213 系列 |
| **轨道式** | 通过轨道供电和固定 | 轨道射灯、磁吸灯 | IEC 60570 / 相应轨道标准 |
| **悬吊式** | 通过吊线/吊杆悬挂 | 吊灯、线条灯、工矿灯 | 按灯具类型归入固定式/可移式 |
| **手提式** | 自带把手/电池，可携带 | 手提探照灯、应急灯 | IEC 60598-2-8 / GB/T 7000.208 系列 |
| **灯串** | 串联/并联的装饰灯串 | 节日灯串、氛围灯串 | IEC 60598-2-20 / GB/T 7000.9 系列 |

> ⚠ **版本提醒**：GB/T 7000 系列正在集中换版，GB/T 7000.1-2023 已于 2026-01-01 实施，各分册（.2xx）版本号与实施日期请以全国标准信息公共服务平台为准。上表只表达「对应关系」，不代表具体版本年份。

**为什么安装方式重要？**
- 它决定**安规测试项目**（防触电、爬电距离、耐热、防火、机械强度）
- 它决定**认证范围**（CCC 目录按固定式/可移式/嵌入式划分）
- 它决定**结构设计**（开孔、承重、维护方式、散热路径）

## 6. 按光分布分（决定「光到哪里、好不好看」）

### 6.1 按光通量分配（CIE 传统五分法）

| 类型 | 向上光通量占比 | 向下光通量占比 | 典型场景 |
|---|---|---|---|
| **直接照明** | 0–10% | 90–100% | 办公、工业、道路 |
| **半直接照明** | 10–40% | 60–90% | 办公、商业 |
| **漫射照明** | 40–60% | 40–60% | 家居、酒店、医疗病房 |
| **半间接照明** | 60–90% | 10–40% | 酒店、展厅 |
| **间接照明** | 90–100% | 0–10% | 氛围、洗墙、高端商业 |

### 6.2 按配光形状分

| 配光类型 | 特点 | 典型产品 |
|---|---|---|
| **窄配光**（如 15°–25°） | 中心光强高、光斑集中 | 射灯、重点照明、远距离投光 |
| **中配光**（如 30°–60°） | 兼顾强度与覆盖 | 筒灯、轨道灯、工矿灯 |
| **宽配光**（如 60°–120°） | 覆盖广、均匀度好 | 面板灯、泛光灯、路灯 |
| **蝙蝠翼配光** | 两侧强、中间弱，抑制近端过亮 | 办公线条灯、教室灯 |
| **非对称配光** | 一侧强、一侧弱 | 洗墙灯、黑板灯、道路灯 |
| **双不对称/偏配光** | 特定方向控制 | 隧道灯、货架灯 |

> **产品经理视角**：配光曲线是灯具的「指纹」。同样的功率和光通量，配光不同，实际效果和眩光水平可能差一倍。**看规格书一定要看配光曲线（IES/LDT 文件），不能只看光通量。**

## 7. 按环境防护分

| 维度 | 分级/标识 | 典型要求 | 适用场景 |
|---|---|---|---|
| **防尘防水** | IP20 / IP44 / IP54 / IP65 / IP66 / IP67 / IP68 | 第一位防尘 0–6，第二位防水 0–9 | 室内/潮湿/户外/水下 |
| **抗冲击** | IK00–IK10（0–20 J） | IK08 常见于户外/工业 | 工矿、道路、公共空间 |
| **防爆** | Ex d / Ex e / Ex i / Ex m / Ex n 等 | 按气体/粉尘类别、温度组别 | 化工、油气、煤矿、粉尘环境 |
| **防腐** | 盐雾等级、材料等级 | 沿海/化工环境 | 海边、化工厂、污水处理 |
| **洁净** | 洁净室等级（ISO 14644） | 不产尘、易清洁、密封 | 医院手术室、电子厂房、制药 |
| **耐温** | 工作环境温度范围 | 如 −20~45 °C / −40~55 °C | 冷库、烤箱附近、户外 |

> IP 与 IK 的定义细节见 [09-术语表](09-术语表.md) 与 [08-标准与认证清单](08-标准与认证清单.md)。

## 8. 按控制方式分

| 控制方式 | 特点 | 典型场景 | 备注 |
|---|---|---|---|
| **开关控制** | 最简单、成本最低 | 家用、简单工程 | 无调光、无状态反馈 |
| **0-10V 调光** | 模拟量、便宜、稳定 | 办公、学校、简单商业 | 无地址、无反馈；0 V 不一定全关 |
| **DALI / DALI-2** | 数字可寻址、可反馈、可分组场景 | 办公、商业、公共建筑 | 需专用总线；DALI-2 支持传感器/DT8 色温 |
| **DMX512** | 高速、适合动态色彩 | 舞台、景观、建筑立面 | 不擅长大规模状态管理 |
| **KNX** | 楼宇级总线，联动 HVAC/遮阳/安防 | 高端公建、酒店、政府项目 | 工程复杂、成本高 |
| **Zigbee / BLE Mesh / Wi-Fi** | 无线、改造方便 | 家用、零售、存量改造 | 2.4 GHz 干扰、跨品牌兼容性 |
| **Matter / Thread** | 面向消费生态的 IP 化标准 | 家用、智能家居 | 工程级场景覆盖仍在发展 |
| **PoE** | 网线供电+控制，IP 化 | 办公、教育、智能楼宇 | 需 PoE 交换机；功率受限 |

> 协议选型的工程判断见 [03-分领域关键参数速查](03-分领域关键参数速查.md) 的「办公」一节。

## 9. 一张「选型决策树」

```
1. 场景是什么？
   ├─ 办公/教育/医疗/商业 → 先查 GB/T 50034-2024 + 行业专项标准
   ├─ 道路/隧道 → 查 GB/T 24827 + CJJ 45 + GB 37478
   ├─ 工业/防爆 → 查 GB/T 3836 + IP/IK
   ├─ 应急 → 查 GB 51309
   └─ 便携/巡逻 → 查 IP/防爆/电池安全 + 客户战术要求

2. 怎么安装？
   ├─ 嵌入 → 开孔尺寸、散热空间、驱动位置
   ├─ 固定 → 承重、接线、维护方式
   ├─ 可移 → 电源线、稳定性、防倾倒
   └─ 轨道 → 轨道标准、接头安全、系统兼容

3. 光要往哪打？
   ├─ 均匀工作面 → 宽配光/蝙蝠翼
   ├─ 重点突出 → 窄配光/中配光
   ├─ 洗墙/氛围 → 非对称/间接
   └─ 远距离 → 窄配光+高光强

4. 环境有多恶劣？
   ├─ 室内干燥 → IP20
   ├─ 潮湿/半户外 → IP44–IP54
   ├─ 户外 → IP65–IP67
   ├─ 水下/地埋 → IP67–IP68
   └─ 爆炸性环境 → Ex 认证

5. 要不要控制？
   ├─ 不调光 → 开关
   ├─ 简单调光 → 0-10V
   ├─ 可寻址/场景 → DALI-2
   ├─ 楼宇联动 → KNX
   └─ 无线改造 → Zigbee/BLE/Matter

6. 目标市场要什么认证？
   └─ CCC / CQC / 能效标识 / CE / UL / DLC / Ex / MA
```

## 10. 常见分类误区

| 误区 | 为什么错 | 正确做法 |
|---|---|---|
| 「家用灯和商用灯是两个物种」 | 产品形态、供应链高度重叠，很多是同平台不同配置 | 看成「同一大类下的两个细分市场」，见 [07](07-家用灯与商用公共建筑照明的异同.md) |
| 「瓦数越大越亮」 | 亮度看光通量（lm）和配光，不看瓦数 | 看 lm、lm/W、配光曲线、照度计算 |
| 「LED 灯都一样」 | 芯片、封装、驱动、散热差异巨大 | 看 BOM 等级、分 bin、驱动品牌、热设计 |
| 「IP65 就能泡水」 | IP65 是防喷水，不是浸水 | 浸水看 IP67/IP68 |
| 「防爆灯就是外壳厚」 | 防爆是系统性的隔爆/增安/本安设计 | 看 Ex 证书、温度组别、隔爆面工艺 |
| 「CCC 认证 = 质量好」 | CCC 只证明安全合规 | 性能看 CQC/能效/第三方检测报告 |
| 「显色指数 Ra 高就颜色好」 | Ra 对 LED 有局限，R9 和 Rf/Rg 更全面 | 看 Ra + R9 + Rf/Rg + 光谱 |
| 「配光曲线都差不多」 | 配光决定眩光、均匀度、有效利用率 | 要 IES/LDT 文件做模拟 |
