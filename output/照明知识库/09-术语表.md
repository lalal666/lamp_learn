# 09 术语表

> **用途**：看规格书、开评审会、和供应商对话时，快速查一个词。
> **读法**：先看「一句话解释」，需要时再看「单位/典型值」。

---

## 1. 光度（光有多少、到哪、多亮）

| 术语 | 英文/符号 | 一句话解释 | 单位/典型值 |
|---|---|---|---|
| **光通量** | Luminous flux, Φ | 光源/灯具发出的总光量 | lm（流明） |
| **光强** | Luminous intensity, I | 某个方向上的发光强度 | cd（坎德拉） |
| **照度** | Illuminance, E | 单位面积接收到的光通量 | lx（勒克斯）= lm/m² |
| **亮度** | Luminance, L | 单位面积、单位立体角的发光强度 | cd/m²（尼特） |
| **光效** | Luminous efficacy | 光源光通量 ÷ 光源功率 | lm/W |
| **灯具效能** | Luminaire efficacy | 整灯光通量 ÷ 整灯输入功率（含驱动） | lm/W |
| **灯具效率** | Luminaire efficiency / LOR | 灯具出射光通量 ÷ 内部光源总光通量 | % |
| **配光曲线** | Luminous intensity distribution | 光强随空间方向分布的曲线 | cd/klm 或 cd |
| **光束角** | Beam angle | 光强降到峰值 50% 的两方向夹角 | °（度） |
| **遮光角** | Shielding angle | 人眼看不到光源的临界角 | ° |
| **中心光强** | Center beam intensity | 光束中心的最大光强 | cd |
| **距高比** | Spacing-to-height ratio, SHR | 灯具间距 ÷ 安装高度 | — |
| **利用系数** | Coefficient of utilization, CU | 到达工作面的光通量 ÷ 灯具总光通量 | — |
| **维护系数** | Maintenance factor, MF | 维护后/初始的照度比 | 常取 0.8 左右 |
| **照度均匀度** | Uniformity, U0 | 最小照度 ÷ 平均照度 | ≥0.6/0.7 常见 |
| **LPD** | Lighting power density | 单位面积照明功率 | W/m² |
| **UGR** | Unified glare rating | 室内统一眩光值，越小越不刺眼 | 办公 ≤19 |
| **GR** | Glare rating | 室外/体育眩光值 | 按标准限值 |
| **反射比** | Reflectance | 表面反射光通量比例 | % |

## 2. 色度（颜色对不对）

| 术语 | 英文/符号 | 一句话解释 | 单位/典型值 |
|---|---|---|---|
| **色温** | Correlated color temperature, CCT | 光的「冷暖」 | K（开尔文），2700–6500 K |
| **显色指数** | Color rendering index, CRI/Ra | 光源还原物体颜色的能力（8 色样平均） | 0–100，≥80 常见 |
| **R9** | Special CRI 9 | 饱和红色显色能力 | 可为负；商业/医疗 >0 |
| **Rf** | Color fidelity index | CIE 224/TM-30 的 99 色样保真度 | 0–100 |
| **Rg** | Gamut index | 平均饱和度偏移 | 100 为中性 |
| **色容差** | SDCM | 与目标色坐标的偏差（麦克亚当椭圆） | ≤3/5 常见 |
| **色坐标** | Chromaticity coordinates | 颜色在色度图上的位置 | (x, y) 或 (u', v') |
| **光谱功率分布** | Spectral power distribution, SPD | 各波长的辐射功率分布 | 曲线 |
| **色漂移** | Color shift | 老化/角度变化导致的颜色偏移 | Δu'v' |
| **同色异谱** | Metamerism | 两个光谱不同但看起来颜色相同的现象 | — |

## 3. 时间与寿命（稳不稳、久不久）

| 术语 | 英文/符号 | 一句话解释 | 单位/典型值 |
|---|---|---|---|
| **频闪** | Flicker | 光输出随时间的快速波动 | — |
| **波动深度** | Percent flicker / modulation depth | (最大值−最小值)/(最大值+最小值) | % |
| **频闪指数** | Flicker index | 波形面积比，评价频闪能量 | 0–1 |
| **PstLM** | Short-term flicker index | 短时闪变指数（0.05–80 Hz） | ≤1 |
| **SVM** | Stroboscopic effect visibility measure | 频闪效应可视度（80 Hz–2 kHz） | ≤0.9（EU） |
| **启动时间** | Starting time | 通电到规定光输出的时间 | s |
| **调光深度** | Dimming range | 可调的最低/最高光输出 | 1%–100% 常见 |
| **调光曲线** | Dimming curve | 亮度随控制信号的变化关系 | 线性/对数/方根 |
| **流明维持** | Lumen maintenance | 使用后光通量保持比例 | % |
| **L70/L80/L90** | Lumen maintenance life | 光通量降到 70%/80%/90% 的时间 | h |
| **B50** | B value | 50% 样品低于该 L 值 | 常见 B50 |
| **LM-80** | IES LM-80 | LED 光源流明维持测试方法 | 6,000 h 起测 |
| **TM-21** | IES TM-21 | 基于 LM-80 的寿命外推方法 | 最多 6× 外推 |
| **LM-79** | IES LM-79 | 整灯光电测试方法 | 光通量/色度/功率 |
| **LM-84** | IES LM-84 | 灯具级流明/颜色维持测试 | 整灯寿命 |
| **老化** | Burn-in / aging | 出厂前通电老化，筛除早期失效 | h |

## 4. 电气（省不省、兼容不兼容）

| 术语 | 英文/符号 | 一句话解释 | 单位/典型值 |
|---|---|---|---|
| **功率因数** | Power factor, PF | 有功功率 ÷ 视在功率 | 商用 ≥0.9 |
| **谐波** | THD | 电流波形畸变程度 | %，按标准限值 |
| **驱动效率** | Driver efficiency | 驱动输出功率 ÷ 输入功率 | 85%–92% |
| **恒流驱动** | Constant current driver | 输出恒定电流 | LED 主流 |
| **恒压驱动** | Constant voltage driver | 输出恒定电压 | 灯带常见 |
| **隔离驱动** | Isolated driver | 输入输出电气隔离 | 安全等级高 |
| **非隔离驱动** | Non-isolated driver | 输入输出不隔离 | 成本低、需结构防护 |
| **纹波** | Ripple | 输出直流上的交流成分 | 越低越好 |
| **浪涌** | Surge | 电网/雷击的瞬时过电压 | kV |
| **漏电流** | Leakage current | 对地泄漏电流 | mA，安规限值 |
| **DALI** | Digital Addressable Lighting Interface | 数字可寻址照明接口（IEC 62386） | 单灯地址/反馈 |
| **0-10V** | 0-10V dimming | 模拟调光接口 | 无地址、便宜 |
| **KNX** | KNX | 楼宇自动化总线 | 灯光+HVAC+遮阳 |
| **DMX512** | DMX512 | 舞台/景观动态灯光控制协议 | 512 通道 |
| **PoE** | Power over Ethernet | 网线供电+控制 | 功率受限 |

## 5. 热与可靠性（为什么坏）

| 术语 | 英文/符号 | 一句话解释 | 单位/典型值 |
|---|---|---|---|
| **结温** | Junction temperature, Tj | LED 芯片 p-n 结的温度 | °C，通常 ≤105–150 |
| **热阻** | Thermal resistance, Rth | 热量传递的阻力 | °C/W |
| **Rjc / Rcs / Rsa** | — | 结到壳 / 壳到散热器 / 散热器到环境 | °C/W |
| **导热界面材料** | TIM | 填充接触面空隙、降低热阻 | 硅脂/垫片/石墨 |
| **光衰** | Lumen depreciation | 使用后光通量下降 | % |
| **色漂移** | Color shift | 使用后颜色偏移 | Δu'v' |
| **加速老化** | Accelerated aging | 高温/高湿/大电流加速失效 | h |
| **失效率** | Failure rate | 单位时间失效比例 | ppm/% |
| **MTBF** | Mean time between failures | 平均无故障时间 | h（参考值） |

## 6. 防护与安全（会不会出事）

| 术语 | 英文/符号 | 一句话解释 | 单位/典型值 |
|---|---|---|---|
| **IP 等级** | Ingress protection | 防尘防水等级 | IP20/IP65/IP67 等 |
| **IK 等级** | Impact protection | 抗冲击等级 | IK00–IK10（0–20 J） |
| **RG 组别** | Risk group | 光生物安全风险组别 | RG0（无风险）–RG3 |
| **蓝光危害** | Blue light hazard | 短波蓝光对视网膜的潜在危害 | 按 GB/T 20145 |
| **防爆型式** | Ex type | 隔爆 d/增安 e/本安 i/浇封 m 等 | Ex d IIB T4 等 |
| **温度组别** | Temperature class | 设备最高表面温度等级 | T1（450°C）–T6（85°C） |
| **设备类别** | Equipment group | I 类煤矿 / II 类气体 / III 类粉尘 | I/II/III |
| **CCC** | China Compulsory Certification | 中国强制性产品认证 | 市场准入 |
| **CQC** | China Quality Certification | 中国质量认证（自愿） | 项目加分 |
| **能效标识** | Energy label | 中国能效等级标识 | 1–3 级 |
| **RoHS** | Restriction of Hazardous Substances | 有害物质限制 | 合规 |

## 7. 光学与结构（怎么把光做出来）

| 术语 | 英文/符号 | 一句话解释 | 备注 |
|---|---|---|---|
| **一次光学** | Primary optics | 封装内部的出光/配光 | LED 透镜/荧光粉 |
| **二次光学** | Secondary optics | 灯具内部的配光/防眩 | 透镜/反光杯/扩散板 |
| **TIR 透镜** | Total internal reflection lens | 全反射透镜，精确配光 | PMMA/PC/硅胶 |
| **反光杯** | Reflector | 反射聚光 | PC 镀铝/铝 |
| **扩散板** | Diffuser | 柔化光线、均匀出光 | PS/PMMA/PC |
| **导光板** | Light guide plate | 侧入式面光源 | PMMA |
| **棱晶板** | Prismatic panel | 防眩/控光 | PMMA/PC |
| **防眩格栅** | Louver | 遮挡大角度光线、降 UGR | PC/铝 |
| **COB** | Chip on board | 多芯片集成封装 | 光密度高 |
| **SMD** | Surface mount device | 贴片封装 | 2835/3030/5050 |
| **CSP** | Chip scale package | 芯片级封装 | 小尺寸/高密度 |
| **分 bin** | Binning | 按电压/光通量/色温/显色分档 | 一致性关键 |
| **荧光粉** | Phosphor | 把蓝光转换成白光的材料 | 决定色温/显色 |
| **透镜** | Lens | 改变光线方向的光学件 | — |

## 8. 场景与设计（光怎么用）

| 术语 | 英文 | 一句话解释 |
|---|---|---|
| **一般照明** | General lighting | 提供空间基础照度的照明 |
| **重点照明** | Accent lighting | 突出特定物体/区域的照明 |
| **洗墙** | Wall washing | 用光均匀照亮墙面 |
| **间接照明** | Indirect lighting | 光先打到表面再反射的照明 |
| **直接照明** | Direct lighting | 光直接投向工作面的照明 |
| **应急照明** | Emergency lighting | 断电时维持照明 |
| **备用照明** | Standby lighting | 火灾等情况下维持工作区域照明 |
| **疏散指示** | Escape route signage | 指示疏散方向的标志灯 |
| **光污染** | Light pollution | 溢散光、上行光、眩光对环境的干扰 |
| **维护系数** | Maintenance factor | 设计时预留的光衰/积灰余量 |
| **照明功率密度** | LPD | 单位面积照明功率，节能指标 |
