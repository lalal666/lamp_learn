# 07 家用灯与商用/公共建筑照明的异同

> **回答的问题**：家用灯和企事业单位、楼宇照明等公共场所的灯，是不是一个大类？有什么细微差异？
> **直接答案**：**是同一个大类（建筑照明），但不是同一个细分市场。** 产品形态和供应链高度重叠，标准体系、可靠性要求、决策链、商业模式差异很大。

---

## 1. 为什么说「同一个大类」

### 1.1 标准体系同源

- **GB/T 50034-2024《建筑照明设计标准》** 同时覆盖：
  - 第 5.2 节 **居住建筑**
  - 第 5.3 节 **公共建筑**（办公、商店、旅馆、医疗、教育、博览、交通、体育等）
- 两者用的是**同一套设计逻辑**：照度、UGR、显色、LPD、均匀度、色温。
- 安全标准也同源：**GB/T 7000 系列**（灯具安全）不分家用/商用，按**安装方式**（固定/可移/嵌入）划分。
- CCC 认证目录也按**安装方式**划分，不按「家用/商用」划分。

### 1.2 产品形态同源

| 产品形态 | 家用 | 商用/公建 |
|---|---|---|
| 筒灯 | ✅ | ✅ |
| 射灯/轨道灯 | ✅ | ✅ |
| 面板灯 | ✅ | ✅ |
| 线条灯 | ✅ | ✅ |
| 灯带 | ✅ | ✅ |
| 吸顶灯 | ✅ | 部分（走廊/卫生间） |
| 吊灯 | ✅ | ✅（酒店/大堂） |
| 壁灯 | ✅ | ✅ |
| 台灯/落地灯 | ✅ | ✅（办公/酒店） |

### 1.3 供应链同源

芯片、封装、驱动、光学件、铝材、注塑、SMT、组装——**大量供应商同时服务两个市场**。很多工厂既做零售品牌代工，也做工程订单。

> **结论**：从「产品大类」看，它们都是**建筑照明**；从「市场细分」看，它们是**两个赛道**。就像「乘用车」和「商用车」都是汽车，但设计、法规、渠道、客户完全不同。

## 2. 12 个维度的差异

| 维度 | 家用/消费级 | 商用/公共建筑 | 对产品经理的影响 |
|---|---|---|---|
| **1. 决策链** | 消费者个人/家庭，冲动+比价 | 甲方/设计院/总包/物业/采购，多方决策 | 家用重营销，工程重资质/案例/参数 |
| **2. 使用时长** | 每天 2–6 h，间歇 | 每天 8–12 h，长期连续 | 工程灯对寿命/散热/频闪要求更高 |
| **3. 设计寿命** | 1–3 年，1–2 万 h 常见 | 5–10 年，5 万 h+ 常见 | 工程灯要用更好的芯片/驱动/散热 |
| **4. 标准体系** | GB/T 7000 + GB/T 9473（台灯）+ CCC | GB/T 50034 + GB/T 31831 + GB 55015 + 行业专项 + CCC/CQC/能效 | 工程要先建「标准库」 |
| **5. 光品质** | 亮、 color 舒服、不刺眼即可 | UGR、LPD、频闪、色容差、配光、Ra/R9 全面考核 | 工程灯要提供完整光度报告 |
| **6. 一致性** | 单灯好看即可，批次差异容忍度高 | 多灯同框，批次/个体色差必须受控 | 工程要严格分 bin + SDCM |
| **7. 可靠性** | 坏了换一个，售后成本低 | 高空/吊顶/公共场所，维护成本极高 | 工程灯要可维护/长寿命/低失效率 |
| **8. 维护方式** | 整灯更换，用户自己装 | 物业/电工维护，需备件/可换光源/驱动 | 工程灯要设计成可维护 |
| **9. 控制** | 开关/遥控/App/语音 | DALI-2/0-10V/KNX/集中控制/传感 | 工程要懂协议和系统集成 |
| **10. 安装** | DIY，免打孔/快装 | 专业施工，开孔/吊顶/布线/调试 | 工程要考虑施工误差和维护空间 |
| **11. 外观** | ID 是核心竞争力 | 功能/隐蔽/与建筑协调 | 家用重颜值，工程重「不突兀」 |
| **12. 商业模式** | 零售/电商，高毛利、快周转 | 项目制/集采，低毛利、长账期、重服务 | 两套成本结构和渠道能力 |

## 3. 认证与合规的差异

| 项目 | 家用 | 商用/公建 |
|---|---|---|
| **CCC** | 强制（目录内） | 强制（目录内） |
| **CQC** | 可选 | 项目常要求 |
| **能效标识** | 部分产品 | 招标常要求 |
| **GB/T 50034 合规** | 通常不涉及 | **必须**（设计/验收依据） |
| **GB/T 31831** | 通常不涉及 | **必须**（LED 室内应用） |
| **频闪/眩光报告** | 少有 | 常要求第三方报告 |
| **配光文件（IES/LDT）** | 少有 | **必须**（做照明模拟） |
| **寿命/LM-80 报告** | 少有 | 常要求 |
| **防爆/应急/医疗专项** | 不涉及 | 按场景强制 |
| **DLC/Energy Star（出口）** | 少有 | 北美项目常要求 |

> **一句话**：**家用的合规是「及格线」，工程的合规是「入场券 + 评分项」。**

## 4. 同一款产品的「家用版 vs 工程版」差异

以**筒灯**为例（示意，不是绝对）：

| 部件/指标 | 家用版 | 工程版 |
|---|---|---|
| **外壳** | 塑料/薄铝，成本优先 | 压铸铝，散热/强度优先 |
| **驱动** | 内置，低成本，PF 较低 | 外置/可换，高 PF、低纹波、长寿命 |
| **光源** | 普通 bin，Ra≥80 | 严格分 bin，Ra≥90/R9>0，SDCM≤3/5 |
| **光学** | 扩散板/简单透镜 | 深防眩/精确配光，UGR≤19 |
| **频闪** | 满足基本要求 | 低波动深度/PstLM/SVM 达标 |
| **防护** | IP20 | IP44/IP65（按场景） |
| **控制** | 开关/遥控 | 0-10V/DALI-2/传感 |
| **寿命** | 15,000–25,000 h | 50,000 h+ |
| **质保** | 1–2 年 | 3–5 年 |
| **包装** | 零售彩盒 | 工程批量包装 |
| **价格** | 零售溢价 | 集采压价 |
| **认证** | CCC | CCC + CQC/能效 + 项目检测报告 |

**面板灯、线条灯、射灯同理**：外形可能一样，内部 BOM、测试标准、质保完全不同。

## 5. 为什么不能「一套 BOM 打两个市场」

| 如果强行共用 | 后果 |
|---|---|
| 用家用 BOM 做工程 | 寿命/频闪/UGR/一致性不达标，验收失败，售后爆炸 |
| 用工程 BOM 做家用 | 成本过高，外观/智能体验不足，卖不动 |
| 用同一套认证 | 工程要的 CQC/能效/配光报告缺失 |
| 用同一套质保 | 家用 1 年 vs 工程 5 年，成本模型不同 |
| 用同一套渠道 | 工程需要设计院/总包关系，零售需要电商/经销商 |

> **正确做法**：**平台化 + 差异化配置**。
> - 共用：光源平台、驱动平台、光学模组、结构平台
> - 差异：分 bin 等级、驱动等级、散热、防护、控制、质保、包装、认证

## 6. 「细微差异」到底细在哪？

很多人以为家用和工程的区别是「功率大小」，其实真正的差异在**使用条件和责任边界**：

### 6.1 使用条件

- **连续点亮时间**：工程 8–12 h/天，家用 2–6 h/天 → 工程对散热/寿命要求高得多
- **环境**：工程可能是吊顶内 40–50 °C、潮湿、粉尘；家用多在 25 °C 室内
- **维护**：工程换灯要搭梯子/拆吊顶/停业；家用踩凳子即可
- **一致性**：工程一排 20 盏灯同框；家用通常单灯或几盏

### 6.2 责任边界

- **家用**：坏了换货/退货，责任相对简单
- **工程**：验收不合格、工期延误、停业损失、安全事故，责任链复杂
- **质保**：工程合同常要求 3–5 年，含光衰、含现场维修
- **认证**：工程要提供完整检测报告、配光文件、寿命报告

### 6.3 决策逻辑

- **家用**：我喜欢、好看、便宜、智能
- **工程**：符合标准、参数达标、案例、价格、交期、服务、账期

> **一句话**：**家用卖「感觉」，工程卖「确定性」。**

## 7. 对产品经理的启示

### 7.1 如果你做工程

1. **先建标准库**：GB/T 50034、GB/T 31831、GB 55015、行业专项
2. **先建测试能力**：积分球/分布光度计/频闪/温升/安规
3. **先建配光文件**：每款产品要有 IES/LDT
4. **先建质保体系**：备件、响应、失效分析
5. **再谈 ID**：工程灯的外观是「不突兀」，不是「惊艳」

### 7.2 如果你做家用

1. **先懂用户**：场景、痛点、审美、价格带
2. **先做体验**：配网、调光、频闪、安装、包装
3. **先控成本**：零售价格敏感，渠道分层
4. **再谈参数**：家用的参数是「支撑体验」，不是「堆到最高」

### 7.3 如果两个都做

- **平台化**：共用核心模组，降低开发成本
- **差异化**：分 bin、驱动、散热、防护、控制、质保
- **独立认证**：工程版单独做 CQC/能效/配光报告
- **独立渠道**：零售团队 vs 工程团队，考核方式不同
- **不要用一套销售话术**：家用讲「护眼/氛围/智能」，工程讲「达标/寿命/维护成本」

## 8. 一张对比总结图

```
                    建筑照明（大类）
                           │
          ┌────────────────┴────────────────┐
          │                                 │
   家用/消费级                        商用/公共建筑
   （卖感觉）                         （卖确定性）
          │                                 │
   ┌──────┴──────┐                  ┌───────┴───────┐
   │ 好看         │                  │ 合规           │
   │ 好装         │                  │ 达标           │
   │ 智能         │                  │ 一致           │
   │ 便宜         │                  │ 耐用           │
   │ 快周转       │                  │ 可维护         │
   └─────────────┘                  └───────────────┘
          │                                 │
   渠道/电商/经销商                  设计院/总包/集采
   1–3 年质保                        3–5 年质保
   CCC 为主                          CCC+CQC+能效+专项
   单灯体验                          系统/项目验收
```
