# 03 分领域关键参数速查

> **回答的问题**：不同领域，主要看哪些参数？典型值是多少？采购时最容易踩什么坑？
> **用法**：先看所在领域的表，再看最后的「通用 10 问」。
> **可信度**：✅ 标准/官方；◐ 行业常见口径；⚠ 随项目/版本变化，必须查原文或实测。

---

## 0. 一张总表：各领域「第一优先级」是什么

| 领域 | 第一优先级 | 一句话 |
|---|---|---|
| 办公 | **UGR + 频闪 + LPD** | 长时间看电脑，眩光和频闪比「亮」更重要 |
| 教育 | **照度均匀度 + 眩光 + 频闪 + 蓝光** | 学生长时间读写，视觉健康是硬指标 |
| 医疗 | **显色 + 洁净 + 无眩光 + 可靠** | 看肤色/伤口/药品，颜色不能骗人 |
| 商业零售 | **显色 + 光束角 + 重点照明** | 让商品好看，比让空间亮更重要 |
| 酒店餐饮 | **氛围 + 显色 + 调光** | 光是装饰材料 |
| 工业 | **防护 + 散热 + 光效 + 维护** | 恶劣环境里，先活下来再谈光 |
| 道路/隧道 | **配光 + 光效 + 寿命 + 防护** | 路面亮度均匀、不晃眼、十年不坏 |
| 体育 | **照度 + 均匀度 + 眩光 + 频闪** | 运动员看得清，摄像机也看得清 |
| 景观 | **防护 + 色彩控制 + 光污染** | 户外风吹雨打，还要好看不扰民 |
| 应急消防 | **响应时间 + 持续时间 + 可靠性** | 火灾时它必须亮，没有第二次机会 |
| 防爆/矿用 | **Ex 等级 + 防护 + 温度组别** | 一次电火花就是事故 |
| 汽车 | **配光 + 法规 + 耐候** | 照亮路，但不能晃对面司机 |
| 便携/巡逻 | **光强/射程 + 续航 + 防护** | 关键时刻照得远、撑得久、摔不坏 |
| 家用 | **安全 + 外观 + 体验 + 价格** | 好看、好装、不刺眼、买得起 |

## 1. 办公照明

### 1.1 必看参数

| 参数 | 常用要求/典型值 | 依据/说明 | 可信度 |
|---|---|---|---|
| 照度（普通办公室） | 300 lx | GB/T 50034-2024 第 5.3 节（办公建筑） | ✅ |
| 照度（高档/精细办公） | 500 lx | 同上 | ◐ |
| UGR | ≤19 | GB/T 50034-2024 | ✅ |
| 照度均匀度 U0 | ≥0.60 | GB/T 50034-2024 | ✅ |
| 显色指数 | Ra ≥80 | GB/T 50034-2024 | ✅ |
| 色温 | 3300–5300 K（常用 4000 K） | 标准建议范围 | ◐ |
| LPD | 普通办公室常见解读 ≤7 W/m² | **以 GB/T 50034-2024 表 6.3.x 与 GB 55015-2021 原文为准** | ⚠ |
| 频闪 | 波动深度/PstLM/SVM 满足 GB/T 31831-2025 | 新版标准新增 PstLM/SVM | ⚠ |
| 灯具效能 | 主流 100–130 lm/W；高效 140+ lm/W | 整灯含驱动 | ◐ |
| 寿命 | L70/L80 ≥50,000 h，质保 3–5 年 | 工程常见口径 | ◐ |
| 控制 | DALI-2 / 0-10V；人体感应/光感 | 按项目智能化等级 | ◐ |
| 防护 | IP20（室内） | 常规 | ✅ |
| 认证 | CCC；项目常要 CQC/能效报告 | 见 [08](08-标准与认证清单.md) | ✅ |

### 1.2 采购陷阱

- **只看瓦数**：24 W 的面板灯可能 2,400 lm，也可能 1,800 lm，差 25%。
- **UGR 只在实验室测**：实际安装高度、间距、背景亮度都会影响 UGR，要看项目模拟报告。
- **「无频闪」没有数据**：要求波动深度/PstLM/SVM 实测值。
- **驱动内置但不可换**：工程维护成本高，坏了要整灯拆。
- **LPD 算错**：只算灯具功率，漏了驱动损耗和应急电源。

### 1.3 该领域最容易被忽略的一项

> **频闪与调光兼容性。** 办公场景大量使用调光/感应，低亮度下的闪烁、关不死、与调光器不兼容，是投诉高发区。

## 2. 教育照明（教室/黑板/台灯）

### 2.1 必看参数

| 参数 | 常用要求/典型值 | 依据/说明 | 可信度 |
|---|---|---|---|
| 课桌面维持平均照度 | ≥300 lx | GB 7793-2010 | ✅ |
| 课桌面照度均匀度 | ≥0.7 | GB 7793-2010 | ✅ |
| 黑板面维持平均照度 | ≥500 lx | GB 7793-2010 | ✅ |
| 黑板面照度均匀度 | ≥0.8 | GB 7793-2010 | ✅ |
| UGR | ≤19（地方/采购常要求 ≤16） | GB 7793-2010；地方标准更严 | ✅/◐ |
| 色温 | 3300–5300 K | GB 40070-2021 | ✅ |
| 显色指数 | Ra ≥80；LED 灯具 R9 >0 | GB 40070-2021 | ✅ |
| 蓝光危害 | 教室灯 RG0；黑板灯 RG0 或 RG1 | GB 40070-2021 | ✅ |
| 频闪 | 按光输出波形频率限值；修订稿拟加 PstLM≤1、SVM≤1 | GB 40070-2021；GB 7793 修订稿 | ✅/⚠ |
| LPD | 常见 ≤8 W/m²；GB/T 50034-2024 口径可能更低 | 以标准原文/项目要求为准 | ⚠ |
| 认证 | CCC；护眼认证（CQC 3155 等）为加分项 | 非强制 | ◐ |

### 2.2 采购陷阱

- **只换灯不调布灯**：教室灯位置、角度、黑板灯安装距离不对，参数再好也达不到均匀度。
- **用「护眼」当标准**：护眼是营销词，真正要看 GB 40070 + GB 7793 + 实测报告。
- **忽略黑板灯**：黑板照度不足是最常见的验收不合格项。
- **忽略维护系数**：新灯达标，两年后光衰+积灰就不达标了。
- **频闪只测「肉眼可见」**：摄像机/手机拍摄下的频闪效应（SVM）也要看。

### 2.3 该领域最容易被忽略的一项

> **安装与维护系数。** 教室照明的验收是在「维护周期末」仍要达标，设计时必须留出光衰和积灰余量（维护系数通常取 0.8 左右，具体查标准）。

## 3. 医疗照明

> ⚠ **注意标准冲突**：GB 51039-2014、JGJ 312-2013、GB/T 50034-2024 对同一房间的照度值可能不同（如手术室 500 lx vs 750 lx）。**项目应以合同约定的设计标准为准，并在图纸会审时明确。**

### 3.1 必看参数

| 参数 | 常用要求/典型值 | 依据/说明 | 可信度 |
|---|---|---|---|
| 病房一般照明 | 100 lx（GB/T 50034-2024/JGJ 312 口径）；GB 51039-2014 为 50 lx | 标准版本差异 | ⚠ |
| 病房阅读照明 | 300 lx | 局部照明 | ◐ |
| 诊室/护士站 | 300 lx | GB/T 50034-2024 口径 | ◐ |
| 手术室一般照明 | 750 lx（GB/T 50034-2024/JGJ 312 口径）；GB 51039-2014 为 500 lx | 手术无影灯另计 | ⚠ |
| UGR | ≤19 | GB/T 50034-2024 | ✅ |
| 显色指数 | 一般 Ra ≥80；手术室 Ra ≥90 | GB/T 50034-2024 / JGJ 312 | ◐ |
| 夜间床头照度 | ≤0.1 lx（儿科 ≤1 lx） | GB 51039-2014 第 8.6.6 条（强条） | ✅ |
| 眩光控制 | 病房宜间接照明/漫反射；避免卧床患者直视光源 | GB 51039-2014 第 8.6.4/8.6.5 条 | ✅ |
| 洁净/消毒 | 易清洁、耐消毒剂、不积尘 | 医院感染控制要求 | ◐ |
| 应急/备用照明 | 手术室、ICU、消防控制室等需备用照明 | GB 51309 / 医院设计规范 | ✅ |
| 手术无影灯 | 单独标准 | GB 50333《医院洁净手术部建筑技术规范》 | ✅ |

### 3.2 采购陷阱

- **用普通办公灯做病房**：眩光、显色、清洁、消毒都不达标。
- **忽略夜间照明**：床头灯太亮影响患者睡眠，且有强条限值。
- **忽略色温一致性**：病房、走廊、护士站色温混用，显得廉价且不舒适。
- **忽略消毒兼容性**：紫外消毒/含氯消毒剂会让普通塑料/涂层快速老化。
- **忽略备用照明**：手术室断电后果严重，必须双路/应急。

### 3.3 该领域最容易被忽略的一项

> **「可清洁性」和「消毒兼容性」。** 医院灯具不是装上去就完事，它要经受反复擦拭和消毒，材料选错一年就发黄开裂。

## 4. 商业零售

### 4.1 必看参数

| 参数 | 常用要求/典型值 | 依据/说明 | 可信度 |
|---|---|---|---|
| 一般照明照度 | 300 lx 左右（按业态） | GB/T 50034-2024 商店建筑表 | ◐ |
| 重点照明 | 环境照明的 3–5 倍 | 行业惯例 | ◐ |
| 显色指数 | Ra ≥90；生鲜/纺织/化妆品更高 | 高端商业常见要求 | ◐ |
| R9 | >0，最好 ≥50 | 红色/肤色/生鲜 | ◐ |
| Rf/Rg | 高端项目 Rf ≥90，Rg 接近 100 | TM-30 / CIE 224 | ◐ |
| 色温 | 2700–4000 K（按品牌调性） | 行业惯例 | ◐ |
| 光束角 | 15°–40°（重点照明） | 按陈列距离/商品尺寸 | ◐ |
| UGR/眩光 | 低眩光，避免顾客直视 | 体验要求 | ◐ |
| 调光 | 0-10V / DALI / 无线 | 按场景控制 | ◐ |
| 频闪 | 低波动深度，尤其摄像/直播场景 | 体验要求 | ◐ |

### 4.2 采购陷阱

- **只追求「亮」**：商业照明是「该亮的地方亮，该暗的地方暗」，全亮等于没重点。
- **Ra 高但 R9 低**：红色商品（生鲜、服装、口红）会发灰。
- **忽略光束角与陈列距离**：同样的灯，装 2 m 和 4 m 效果完全不同。
- **忽略色容差**：同一排射灯色差明显，高级感全无。
- **生鲜灯合规风险**：不得通过特殊光谱改变食用农产品真实色泽，需自查最新监管要求。

### 4.3 该领域最容易被忽略的一项

> **色容差（SDCM）和批间一致性。** 商业空间是「多灯同框」，单灯好看没用，一排灯颜色不一致就露馅。

|---|---|---|---|

| 防护 | IP65/IP66 常见 | 环境要求 | ◐ |
| 抗冲击 | IK08+ | 矿山/化工 | ◐ |
| 材质 | 压铸铝/不锈钢/工程塑料；隔爆面工艺 | 结构安全 | ◐ |
| 电缆引入 | 与电缆外径匹配的引入装置 | 安装关键 | ✅ |
| 认证 | Ex 防爆合格证；煤矿需 MA 煤安证 | 强制 | ✅ |
| 矿用标准 | MT/T 221 系列 | 煤矿灯具 | ✅ |

**最容易忽略**：**隔爆面保护与电缆引入装置匹配**。安装时磕伤隔爆面、或用错引入装置，防爆认证等于作废。

## 14. 家用照明（作为对照）

| 参数 | 常见关注点 | 说明 |
|---|---|---|
| 光通量 | 按房间面积选 | 一般 100–300 lm/m² 量级（经验值） |
| 色温 | 2700–4000 K；可调色温流行 | 暖光温馨，冷光清醒 |
| 显色 | Ra ≥80；高端 ≥90 | 餐桌/化妆区更重要 |
| 频闪 | 低波动深度 | 手机拍摄可初判 |
| 蓝光 | RG0/RG1 | 台灯看 GB/T 9473-2022 |
| 智能 | 配网、调光、场景、语音 | 生态兼容性 |
| 外观 | ID、材质、颜色 | 决策权重高 |
| 安装 | 免打孔/快装/磁吸 | 降低退货率 |
| 价格 | 敏感 | 性价比 |
| 认证 | CCC | 强制 |

**最容易忽略**：**「亮度可调」不等于「调光体验好」**。低亮度闪烁、调光不平滑、关灯后微亮，是家用智能灯的高频差评。

## 15. 通用 10 问（任何领域都适用）

拿到任何一款灯，先问这 10 个问题：

1. **整灯光通量多少 lm？整灯输入功率多少 W？** → 算真实灯具效能。
2. **配光曲线/IES 文件有没有？** → 判断光斑、均匀度、眩光。
3. **Ra 多少？R9 多少？SDCM 多少？** → 判断颜色。
4. **UGR 多少？遮光角多少？** → 判断眩光。
5. **频闪：波动深度/PstLM/SVM 实测多少？** → 判断视觉舒适。
6. **寿命是 L70 还是 L80？B 值多少？什么温度/电流下测的？** → 判断寿命含金量。
7. **驱动是谁家的？PF、THD、效率、调光协议、保护功能？** → 判断系统可靠性。
8. **IP/IK 多少？有没有第三方报告？** → 判断环境适应。
9. **过了哪些认证？证书覆盖哪些型号？** → 判断合规。
10. **质保几年？含不含光衰？坏了怎么修/换？** → 判断全生命周期成本。
