# 10 项目落地检查清单

> **用途**：可直接打印/复制到项目管理工具，按阶段逐项勾选。
> **用法**：每个 Gate 前逐项确认；未通过项写「负责人 + 截止日期」，不允许「默认为通过」。

---

## A. 立项前（S0）

- [ ] 目标场景明确（办公/教育/医疗/商业/工业/道路/其他）
- [ ] 目标客户/决策链明确（终端/经销商/工程商/甲方/总包）
- [ ] 竞品 2–3 款已拆解（价格、参数、卖点、渠道）
- [ ] 差异化卖点能一句话说清
- [ ] 目标成本/目标售价已测算
- [ ] 目标销量/毛利/战略目标已确认
- [ ] 目标上市时间已倒排
- [ ] 项目负责人/团队/预算已到位

**Gate 判定**：能回答「谁愿意为什么付多少钱」。

---

## B. 需求定义（S1）

- [ ] 5W1H 已完成（谁用/在哪/多久/解决什么/为什么现在/怎么装）
- [ ] 现场已调研（照片、尺寸、吊顶/配电/维护条件）
- [ ] 安装方式明确（嵌入/固定/吊装/轨道/可移）
- [ ] 控制方式明确（开关/0-10V/DALI/KNX/无线/传感）
- [ ] 维护方式明确（整灯更换/可换光源/可换驱动/前维护）
- [ ] 使用环境明确（温度/湿度/粉尘/腐蚀/防爆/户外）
- [ ] 需求已分级（Must/Should/Could/Won't）
- [ ] 每条需求可量化/可验收

**Gate 判定**：需求清单无「形容词」，全部可测。

---

## C. 标准与合规（S2）

- [ ] 目标市场已确定（中国/欧盟/北美/其他）
- [ ] 强制安全标准已列（GB/T 7000.1-2023 + 对应分册）
- [ ] 驱动安全标准已列（GB/T 19510 系列）
- [ ] 光生物安全已列（GB/T 20145 / GB/Z 39942）
- [ ] EMC 标准已列（GB/T 17743 / GB 17625.1 / GB/T 17626）
- [ ] 能效标准已列（GB 30255 / GB 38450 / GB 37478，按产品）
- [ ] 设计标准已列（GB/T 50034-2024 / GB 55015-2021）
- [ ] 行业专项已列（教育/医疗/应急/防爆/汽车等）
- [ ] 认证清单已列（CCC/CQC/能效/CE/UL/DLC/Ex/MA）
- [ ] 认证周期已排进项目计划
- [ ] 标准版本已在官方平台复核（非二手资料）
- [ ] 「标准 → 参数 → 测试 → 证据」映射表已建立

**Gate 判定**：合规矩阵无遗漏，认证排期不晚于上市前 8 周。

---

## D. 规格书（S3）

### D.1 光学

- [ ] 光通量（lm）及公差
- [ ] 灯具效能（lm/W，整灯含驱动）
- [ ] 配光曲线/IES-LDT 文件要求
- [ ] 光束角/中心光强（如适用）
- [ ] 色温（K）及公差
- [ ] Ra、R9（高端加 Rf/Rg）
- [ ] SDCM 色容差
- [ ] UGR/遮光角（室内）
- [ ] 频闪指标（波动深度/PstLM/SVM）
- [ ] 照度/均匀度目标（如做设计）
- [ ] 测试条件（温度、电压、稳定时间）

### D.2 电气

- [ ] 输入电压范围
- [ ] 额定功率及公差
- [ ] PF、THD
- [ ] 驱动效率
- [ ] 调光协议/调光深度/调光曲线
- [ ] 保护功能（OVP/OCP/SCP/OTP）
- [ ] 浪涌等级
- [ ] 待机功耗
- [ ] 接线方式/端子规格

### D.3 热与环境

- [ ] 工作环境温度范围
- [ ] 存储温度/湿度
- [ ] 结温上限
- [ ] 散热方式
- [ ] 降额曲线
- [ ] IP 等级
- [ ] IK 等级
- [ ] 盐雾/防腐（如适用）
- [ ] 洁净/消毒兼容（医疗）

### D.4 结构与安装

- [ ] 外形尺寸/开孔尺寸
- [ ] 材质/表面处理
- [ ] 重量
- [ ] 安装方式/配件
- [ ] 维护方式
- [ ] 包装要求

### D.5 可靠性与质保

- [ ] 寿命指标（L70/L80 + B 值 + 测试条件）
- [ ] 开关循环次数
- [ ] 质保年限/范围（含不含光衰）
- [ ] 备件供应年限

### D.6 合规

- [ ] 标准清单
- [ ] 认证清单
- [ ] 报告要求（第三方/自测）
- [ ] 标识/说明书要求

**Gate 判定**：每个指标都有「数值 + 公差 + 测试条件 + 测试方法 + 验收方式」。

---

## E. 概念与详细设计（S4–S5）

### E.1 方案对比

- [ ] 至少 3 套方案对比（光源/驱动/光学/散热/结构）
- [ ] 对比维度：性能/成本/可靠性/可制造性/供应链/认证/外观
- [ ] 主方案 + 备选方案已选定
- [ ] 取舍理由已记录

### E.2 接口评审

- [ ] 光学 ↔ 光源（尺寸/发光面/配光）
- [ ] 光源 ↔ 驱动（串并/电压/电流/调光）
- [ ] 驱动 ↔ 结构（尺寸/散热/接线/绝缘）
- [ ] 散热 ↔ 结构（导热路径/接触面/压力）
- [ ] 结构 ↔ 安装（开孔/承重/维护空间）
- [ ] 整灯 ↔ 标准（爬电/接地/IP/防火）

### E.3 仿真/计算

- [ ] 光学仿真（配光/照度/UGR）
- [ ] 热仿真（结温/散热器）
- [ ] 电路计算/仿真
- [ ] 结构强度/公差分析
- [ ] DFM/DFA 评审

**Gate 判定**：设计评审通过，无未闭环的「红色」问题。

---

## F. 手板/样机（S6）

- [ ] 手板已装配（能装/好装）
- [ ] 光电初测（积分球/分布光度计）
- [ ] 温升初测（额定功率连续点亮）
- [ ] 安规预测试（耐压/绝缘/接地）
- [ ] EMC 预测试
- [ ] 关键指标 ≥ 规格 90%
- [ ] 重大结构问题已解决

**Gate 判定**：可以进入 DVT，无「推倒重来」风险。

---

## G. 设计验证 DVT（S7）

### G.1 光电

- [ ] 光通量/效能
- [ ] 配光/光束角
- [ ] 色温/Ra/R9/SDCM
- [ ] 频闪（波动深度/PstLM/SVM）
- [ ] 调光范围/曲线/兼容性
- [ ] 照度/均匀度/UGR（如做设计）

### G.2 热

- [ ] 温升/结温（最恶劣环境温度）
- [ ] 高温工作
- [ ] 低温启动
- [ ] 降额验证

### G.3 安规

- [ ] 耐压
- [ ] 绝缘电阻
- [ ] 接地连续性
- [ ] 爬电距离/电气间隙
- [ ] 异常状态（开路/短路/过载）
- [ ] 防火/耐热/耐起痕

### G.4 EMC

- [ ] 传导骚扰
- [ ] 辐射骚扰
- [ ] 谐波电流
- [ ] 电压波动/闪烁
- [ ] 抗扰度（ESD/EFT/浪涌/传导抗扰）

### G.5 环境/机械

- [ ] 高温/低温/湿热/温度循环
- [ ] 盐雾（如适用）
- [ ] 振动/跌落
- [ ] IP/IK
- [ ] 安装强度/吊装

### G.6 寿命

- [ ] 老化（burn-in）
- [ ] LM-80/TM-21 或整灯加速
- [ ] 光衰/色漂移数据
- [ ] 驱动寿命评估

### G.7 系统

- [ ] 调光器兼容
- [ ] 控制系统兼容（DALI/KNX/无线）
- [ ] 应急系统兼容（如适用）

**Gate 判定**：所有 Must 项通过；问题闭环；认证样品可送。

- [ ] 直通率达标（如 ≥95%）
- [ ] 关键工序 CPK 达标
- [ ] 来料一致性验证
- [ ] 包装/物流验证
- [ ] 试产问题清单闭环

**Gate 判定**：可以量产，无「试产靠人盯」的工序。

- [ ] 安装说明书

- [ ] 认证证书/报告
