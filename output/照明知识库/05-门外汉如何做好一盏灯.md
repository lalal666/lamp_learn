# 05 门外汉如何做好一盏灯

> **回答的问题**：我不是光学/电子出身，怎么把一个灯具产品从 0 做到量产？
> **核心观点**：产品经理不需要自己画透镜、绕变压器，但必须**会定义、会拆解、会取舍、会验收**。你是系统的集成者，不是某个模块的专家。

---

## 0. 先定义什么叫「好」

「好灯」不是一个绝对标准，而是：

> **在目标场景、目标标准、目标成本、目标交期的约束下，稳定地满足光、色、安全、寿命、安装、维护的综合要求。**

所以，做灯的第一步不是选灯珠，而是回答四个问题：

| 问题 | 答案决定什么 |
|---|---|
| **卖给谁、用在哪？** | 场景、标准、参数权重 |
| **必须满足哪些强制标准？** | 认证、测试、设计边界 |
| **成本上限/目标售价？** | 方案选型、供应链 |
| **什么时候上市？** | 开发周期、认证周期、模具周期 |

> **门外汉最常见的错误**：一上来就问「用哪个灯珠、多少瓦」，而不是先问「这个灯要在什么场景、满足什么标准、卖多少钱」。

## 1. 全流程：12 个阶段（Stage-Gate）

| 阶段 | 名称 | 核心动作 | 交付物 | 退出准则 |
|---|---|---|---|---|
| **S0** | 立项 | 场景/客户/竞品/商业目标 | 立项书 | 商业逻辑成立 |
| **S1** | 需求定义 | 用户、场景、安装、维护、竞品拆解 | PRD/需求清单 | 需求可量化 |
| **S2** | 标准与合规 | 列强制标准、认证清单、目标市场法规 | 合规矩阵 | 标准无遗漏 |
| **S3** | 规格书 | 光/色/电/热/结构/环境/控制/成本 | 产品规格书 | 指标可测试 |
| **S4** | 概念方案 | 光源/驱动/光学/散热/结构方案对比 | 方案对比表 | 选定主方案 |
| **S5** | 详细设计 | 光学仿真、热仿真、电路、结构、DFM | 3D/原理图/BOM | 设计评审通过 |
| **S6** | 手板/样机 | 打样、装配、初测 | 样机+初测报告 | 关键指标达标 |
| **S7** | 设计验证（DVT） | 光电/热/安规/EMC/可靠性 | DVT 报告 | 全部通过 |
| **S8** | 认证 | CCC/CQC/CE/UL/DLC 等 | 证书/报告 | 拿证 |
| **S9** | 试产（PVT） | 模具、治具、SOP、测试工位 | 试产报告 | 直通率达标 |
| **S10** | 量产/上市 | IQC/IPQC/OQC、包装、安装说明 | 量产文件 | 稳定出货 |
| **S11** | 售后/迭代 | 失效分析、客诉、降本、迭代 | FA 报告/版本 | 闭环 |

> **Gate 的意义**：每个阶段结束前评审，不达标不进入下一阶段。**返工的成本随阶段指数上升**：S3 改一个参数可能只是改文档，S9 改一个参数可能要改模具、重做认证。

---

## 2. 逐阶段拆解

### S0 立项：先想清楚「为什么做」

**要回答**：
- 目标市场：家用/办公/教育/医疗/工业/道路/出口？
- 客户是谁：终端消费者、经销商、工程商、甲方、总包？
- 竞品是谁：价格带、参数、卖点、渠道？
- 我们的差异化：更便宜、更好看、更亮、更耐用、更智能、交期更快？
- 商业目标：销量、毛利、战略卡位？

**交付物**：一页纸立项书（市场、客户、竞品、差异化、目标成本、目标售价、目标上市时间）。

**退出准则**：能说清楚「谁愿意为什么付多少钱」。

---

### S1 需求定义：把「感觉」变成「可量化」

**5W1H**：

| 维度 | 问题 | 例子 |
|---|---|---|
| Who | 谁用？谁装？谁维护？ | 办公职员、电工、物业 |
| Where | 用在哪？室内/户外/潮湿/防爆？ | 办公室吊顶、地下车库 |
| When | 用多久？白天/夜晚？连续/间歇？ | 每天 10 h，5 年 |
| What | 要解决什么问题？ | 看电脑不刺眼、验收达标 |
| Why | 为什么现在做？ | 旧灯频闪、能耗高、客户投诉 |
| How | 怎么装、怎么控、怎么维护？ | 嵌入 600×600、DALI 调光、前维护 |

**输出**：需求清单（Must/Should/Could/Won't），每条尽量可量化。

**门外汉技巧**：去现场看。拍照片、量尺寸、问电工、看配电箱、看吊顶结构。**很多需求问题，在办公室里想不出来。**

---

### S2 标准与合规：先列「不能碰的红线」

**动作**：
1. 确定目标市场（中国/欧盟/美国/其他）
2. 列强制标准（安全、EMC、能效、行业专项）
3. 列认证（CCC/CE/UL/DLC/Ex/MA）
4. 列客户/项目附加要求（招标文件、企业标准）
5. 做成「标准 → 参数 → 测试」映射表

**必须覆盖的类别**：

| 类别 | 中国常见标准 | 说明 |
|---|---|---|
| 灯具安全 | GB/T 7000.1-2023 + GB/T 7000.2xx | 按安装方式选分册 |
| 驱动安全 | GB 19510.1 / GB/T 19510.213 | LED 驱动 |
| 光生物安全 | GB/T 20145 / GB/Z 39942 | 蓝光危害 |
| EMC | GB/T 17743 / GB 17625.1 / GB/T 17626 | 骚扰+抗扰 |
| 能效 | GB 30255 / GB 38450 / GB 37478 | 按产品类型 |
| 应用要求 | GB/T 31831-2025 | LED 室内照明 |
| 设计标准 | GB/T 50034-2024 / GB 55015-2021 | 照度、UGR、LPD |
| 行业专项 | GB 51309（应急）、GB 7793/GB 40070（教育）、GB 51039（医疗）、GB/T 3836（防爆） | 按场景 |

> 完整清单见 [08-标准与认证清单](08-标准与认证清单.md)。

**退出准则**：合规矩阵无遗漏，认证周期已排进项目计划。

---

### S3 规格书：把需求翻译成「可测试的指标」

一份好的灯具规格书，至少包含 8 个模块：

| 模块 | 必写内容 |
|---|---|
| **1. 产品定义** | 名称、型号、用途、安装方式、目标市场 |
| **2. 光学** | 光通量、灯具效能、配光、光束角、CCT、Ra/R9、SDCM、UGR、频闪 |
| **3. 电气** | 输入电压、功率、PF、THD、调光协议、保护、浪涌 |
| **4. 热** | 工作环境温度、结温上限、散热方式、降额曲线 |
| **5. 结构** | 尺寸、开孔、材质、表面处理、重量、IP/IK |
| **6. 控制** | 开关/调光/传感/通信协议/应急 |
| **7. 可靠性与质保** | 寿命（L70/L80+B）、开关次数、质保年限与范围 |
| **8. 合规与认证** | 标准清单、认证清单、报告要求 |

**写法要求**：
- 每个指标写**数值 + 公差 + 测试条件 + 测试方法**
- 区分 **Must（必须） / Target（目标） / Nice（加分）**
- 明确**验收方式**（自测/第三方/现场）

> **门外汉技巧**：不会写指标，就抄标准 + 抄竞品规格书 + 让供应商填。**但必须自己核对标准，不能供应商说什么就是什么。**

---

### S4 概念方案：至少比 3 套

| 维度 | 方案 A | 方案 B | 方案 C |
|---|---|---|---|
| 光源 | SMD | COB | 模组 |
| 驱动 | 非隔离内置 | 隔离外置 | 恒压+DC-DC |
| 光学 | 扩散板 | 透镜+反光杯 | 导光板 |
| 散热 | 铝挤 | 压铸 | 塑料+铝基板 |
| 结构 | 一体 | 分体 | 模块化 |
| 成本 | 低 | 中 | 高 |
| 风险 | 散热 | 成本 | 供应链 |

**评估维度**：性能、成本、可靠性、可制造性、供应链、认证难度、外观。

**退出准则**：选定主方案 + 备选方案，明确取舍理由。

---

### S5 详细设计：让专业的人做专业的事

**你需要盯的不是画图，而是「接口」和「约束」**：

| 接口 | 要确认什么 |
|---|---|
| 光学 ↔ 光源 | 透镜/反光杯与灯珠尺寸、发光面、配光匹配 |
| 光源 ↔ 驱动 | 串并方式、电压/电流、调光兼容 |
| 驱动 ↔ 结构 | 驱动尺寸、散热、接线、绝缘 |
| 散热 ↔ 结构 | 导热路径、接触面、螺丝压力 |
| 结构 ↔ 安装 | 开孔、承重、维护空间 |
| 整灯 ↔ 标准 | 爬电距离、接地、IP、防火 |

**必须做的仿真/计算**：
- 光学仿真（配光、照度、UGR）
- 热仿真（结温、散热器）
- 电路仿真/计算（驱动、保护）
- 结构强度/公差分析
- DFM/DFA（可制造性/可装配性）

---

### S6 手板/样机：快速暴露问题

**做什么**：
- 3D 打印/CNC/开简易模
- 装配验证（能不能装、好不好装）
- 光电初测（积分球/分布光度计）
- 温升初测（热电偶/热像仪）
- 安规预测试（耐压、绝缘、接地）
- EMC 预测试

**退出准则**：关键指标达到规格的 90% 以上，重大结构问题已解决。

---

### S7 设计验证（DVT）：把「能亮」变成「能卖」

**测试清单**：

| 类别 | 项目 |
|---|---|
| **光电** | 光通量、效能、配光、色度、频闪、调光 |
| **热** | 温升、结温、高温/低温工作、降额 |
| **安规** | 耐压、绝缘、接地、爬电距离、异常状态 |
| **EMC** | 传导/辐射骚扰、谐波、抗扰度 |
| **环境** | 高低温、湿热、温度循环、盐雾、IP/IK |
| **机械** | 振动、跌落、安装强度、开关循环 |
| **寿命** | 老化（burn-in）、LM-80/TM-21 或整灯加速 |
| **兼容性** | 调光器、控制系统、应急系统 |

**退出准则**：全部 Must 项通过；Target 项有明确结论；问题闭环。

---

### S8 认证：别让证书卡住上市

| 认证 | 适用 | 周期（量级） | 注意 |
|---|---|---|---|
| **CCC** | 中国强制（固定/可移/嵌入式灯具等） | 数周–数月 | 型号覆盖、工厂检查 |
| **CQC** | 自愿/项目要求 | 数周 | 性能/安全 |
| **能效标识** | 室内 LED 产品 | 数周 | GB 30255/38450 |
| **CE** | 欧盟 | 数周 | LVD/EMC/RoHS/ErP |
| **UL/ETL** | 北美 | 数月 | 安规 |
| **DLC/Energy Star** | 北美能效补贴 | 数月 | 性能测试 |
| **Ex** | 防爆 | 数月 | 防爆认证 |
| **MA** | 煤矿 | 数月 | 煤安认证 |
| **E-mark** | 汽车出口 | 数月 | 法规测试 |

> **PM 提醒**：认证不是「最后一步」，而是**从 S2 就要排进计划**。改一个驱动/灯珠，可能触发重测。

---

### S9 试产（PVT）：验证「能不能稳定地做出来」

**关注**：
- 模具/治具/工装是否到位
- SOP/作业指导书是否可执行
- 测试工位/治具是否稳定
- 直通率/不良率
- 来料一致性
- 包装/物流

**退出准则**：直通率达到目标（如 95%+），关键工序 CPK 达标，测试与量产一致。

---

### S10 量产/上市：把「样品」变成「商品」

**必须建立**：
- IQC（来料检验）：灯珠、驱动、光学件、结构件
- IPQC（过程检验）：SMT、装配、老化、测试
- OQC（出货检验）：外观、光电、安规抽检
- 变更管理（ECN）：任何材料/工艺变更都要评估
- 追溯体系：批次/序列号

**上市资料**：安装说明、规格书、认证证书、质保条款、维护手册。

---

### S11 售后/迭代：真正的品质从这里开始

- 客诉分类：不亮、闪烁、光衰、色差、漏水、异响、安装问题
- 失效分析（FA）：拿到不良品，做拆解/测试/复现
- 根因 → 设计/工艺/来料/使用 → 纠正措施
- 版本迭代：降本、提效、修 bug

> **一句话**：**售后数据是下一款产品最好的需求文档。**

## 3. 门外汉的三条铁律

### 铁律一：先抄标准，再谈创新

- 把目标市场的强制标准列成清单
- 每条标准映射到具体参数和测试
- 设计前就知道「红线在哪」
- **创新只能在标准允许的空间里做**

> 很多「创新」其实是「不合规」。比如为了好看把出光面做成镜面、为了薄把散热省掉、为了便宜用非隔离却不做绝缘结构。

### 铁律二：先算热，再谈光

- 用 `P_heat ≈ P_in × (1 − η)` 估算发热
- 用 `Tj ≈ Ta + P_heat × (Rjc + Rcs + Rsa)` 估算结温
- 结温每升约 10 °C，寿命大致减半
- **散热不行，光效和寿命都是纸面数字**

> 门外汉最容易忽略热，因为样品在空调房里亮 10 分钟看不出问题。**一定要在高温箱里、额定功率下、连续点亮测。**

### 铁律三：先定供应链，再定 ID

- 灯珠/驱动/光学件/铝材的**可得性、MOQ、交期、二供**
- 关键器件有没有停产风险
- 认证是否绑定特定型号
- **ID 再好看，做不出来/交不了货就是零**

> 一个常见翻车：ID 定了一个特殊尺寸的透镜，开模费几十万，交期 12 周，项目直接延期。

## 4. 五个必须做的测试

| # | 测试 | 为什么必须 |
|---|---|---|
| 1 | **积分球/分布光度计** | 光通量、效能、色度、配光的真实数据 |
| 2 | **温升/结温** | 寿命和光衰的根因 |
| 3 | **安规（耐压/绝缘/接地/异常）** | 认证和人身安全 |
| 4 | **EMC（骚扰/谐波/抗扰）** | 认证和系统兼容 |
| 5 | **可靠性（高低温/湿热/振动/跌落/盐雾/开关）** | 真实环境下的存活能力 |

> 如果预算有限，至少做 **1 + 2 + 3**。EMC 和可靠性可以在认证前补。

## 5. 常见翻车点（按阶段）

| 阶段 | 翻车点 | 后果 | 预防 |
|---|---|---|---|
| S1 | 需求没量化 | 做出来「感觉不对」 | 5W1H + 现场调研 |
| S2 | 漏标准/漏认证 | 上市延期/退货 | 合规矩阵 + 第三方咨询 |
| S3 | 指标无测试条件 | 供应商钻空子 | 规格书写清测试方法 |
| S4 | 只比价格 | 可靠性差/售后爆炸 | 多方案评估 + 样机对比 |
| S5 | 光学/热/电不匹配 | 闪烁、光衰、死灯 | 接口评审 + 仿真 |
| S6 | 手板不做热测试 | 量产才发现散热不够 | 额定功率连续点亮 |
| S7 | 只测样品不测批次 | 批间色差/不良 | 多批次抽样 |
| S8 | 认证型号不覆盖 | 出货被查 | 证书型号核对 |
| S9 | 试产≠量产 | 直通率低 | PVT + SOP + 治具 |
| S10 | 无变更管理 | 偷偷换料导致批量事故 | ECN + 来料检验 |
| S11 | 不做失效分析 | 同一个问题反复发生 | FA 闭环 |

## 6. 团队需要哪些角色

| 角色 | 负责 | 门外汉 PM 怎么配合 |
|---|---|---|
| **光学工程师** | 配光、透镜、仿真、UGR | 给场景和目标，别替他们画透镜 |
| **电子工程师** | 驱动、PCB、调光、EMC | 明确调光协议、认证要求 |
| **结构工程师** | 外壳、散热、安装、防水 | 明确安装条件、维护方式 |
| **热工程师** | 热仿真、散热设计 | 提供环境温度、功率、寿命目标 |
| **测试/认证工程师** | 光电、安规、EMC、认证 | 提前排期，别卡在最后 |
| **品质工程师** | IQC/IPQC/OQC、可靠性 | 建立检验标准和抽检方案 |
| **供应链/采购** | 器件选型、二供、交期 | 关键器件提前锁价锁产能 |
| **工业设计** | 外观、CMF | 在可制造性约束内做设计 |
| **项目经理** | 计划、风险、跨部门 | 盯 Gate，别让问题滚雪球 |

> **门外汉 PM 的核心价值**：不是替工程师做技术决定，而是**确保所有人对「什么算好、什么不能碰、什么时候交付」有共识**。

## 7. 第一个项目怎么起步（90 天路线）

| 周 | 做什么 |
|---|---|
| **第 1–2 周** | 选一个具体场景（如「办公 600×600 面板灯」）；现场调研；拆 2–3 个竞品 |
| **第 3–4 周** | 列标准清单；写需求清单；确定目标成本和认证 |
| **第 5–6 周** | 写规格书；找 3 家供应商打样/报价；做方案对比 |
| **第 7–8 周** | 手板装配；积分球/温升初测；安规预测试 |
| **第 9–10 周** | 设计评审；修正方案；准备 DVT |
| **第 11–12 周** | DVT 测试；认证送样；试产准备 |
| **第 13 周** | 复盘：哪些假设错了？下一版怎么改？ |

> **建议**：第一个项目不要选「最难的」（防爆/汽车/医疗），选一个**标准清晰、供应链成熟、能快速拿到测试数据**的品类，比如办公面板灯或筒灯。
