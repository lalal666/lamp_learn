# 02 评价参数维度

> **回答的问题**：评价一盏灯，到底该看哪些维度？不同领域为什么看的东西不一样？
> **核心观点**：所有照明参数可以归为**七层金字塔**；不同领域的差别，本质是**各层权重不同**，而不是参数本身不同。

---

## 1. 七层参数金字塔

```
                    ┌──────────────────────────┐
              L7    │  体验与商业层             │  好不不好用、卖不卖得动
                    │  外观/安装/维护/智能/成本  │
                    ├──────────────────────────┤
              L6    │  环境与可靠层             │  耐不耐用
                    │  IP/IK/温度/盐雾/寿命/质保 │
                    ├──────────────────────────┤
              L5    │  电气与能效层             │  省不省、兼容不兼容
                    │  功率/PF/THD/效率/调光/浪涌│
                    ├──────────────────────────┤
              L4    │  时间稳定层               │  稳不稳、久不久
                    │  频闪/调光/流明维持/色漂移 │
                    ├──────────────────────────┤
              L3    │  色度层                   │  颜色对不对
                    │  CCT/Ra/R9/Rf/Rg/SDCM     │
                    ├──────────────────────────┤
              L2    │  光度层                   │  亮不亮、照到哪、晃不晃眼
                    │  光通量/光效/配光/照度/UGR │
                    ├──────────────────────────┤
              L1    │  安全与合规层             │  会不会出事 —— 一票否决
                    │  电气/光生物/EMC/机械/防火 │
                    └──────────────────────────┘
```

**使用原则**：
1. **L1 是一票否决层**，不能被 L2–L7 的高分抵消。安全不合格，其他都免谈。
2. **L2–L4 是「光」的三层**，决定照明效果和视觉舒适度。
3. **L5–L6 是「工程」的两层**，决定能不能在真实环境里长期稳定工作。
4. **L7 是「商业」层**，决定产品能不能卖、好不好装、好不好维护。

## 2. 逐层拆解

### L1 安全与合规层（一票否决）

| 参数/要求 | 含义 | 典型标准 | 常见坑 |
|---|---|---|---|
| **电气安全** | 防触电、绝缘、耐压、接地、爬电距离、电气间隙、防火、耐热、耐起痕 | GB/T 7000.1-2023 / IEC 60598-1 | 爬电距离不足；接地不可靠；内部线径过细 |
| **驱动安全** | 驱动电源的绝缘、异常状态、温升、短路/开路保护 | GB 19510.1 / GB/T 19510.213 / IEC 61347 | 驱动与灯板未隔离；异常状态起火 |
| **光生物安全** | 蓝光危害、紫外/红外危害，分 RG0–RG3 | GB/T 20145-2006、GB/Z 39942-2021 / IEC 62471 | 只标「无蓝光危害」但无 RG 等级和测试报告 |
| **EMC** | 传导/辐射骚扰、谐波电流、电压波动、抗扰度 | GB/T 17743、GB 17625.1、GB/T 17626 系列 | 便宜驱动不过谐波；调光时干扰 |
| **机械安全** | 承重、防倾倒、防坠落、抗冲击 | GB/T 7000.1、GB/T 20138 / IEC 62262 | 吊装件强度不足；轨道灯掉落 |
| **环境安全** | IP 防护、防爆、防腐、阻燃 | GB/T 4208、GB/T 3836 系列 | IP 标称与实测不符；防爆认证造假 |
| **材料安全** | RoHS、REACH、阻燃等级 | RoHS 2011/65/EU 等 | 塑料件阻燃不达标；焊料含铅 |
| **认证合规** | CCC、CQC、CE、UL、Ex、MA 等 | 见 [08](08-标准与认证清单.md) | 认证范围与出货型号不一致 |

> **判断口诀**：L1 不看「分数」，只看「有没有」。有没有证书、有没有报告、证书覆盖的型号对不对。

### L2 光度层（亮不亮、照到哪、晃不晃眼）

| 参数 | 符号/单位 | 含义 | 怎么用 |
|---|---|---|---|
| **光通量** | Φ，lm | 光源/灯具发出的总光量 | 判断「总共多少光」；替换灯具时按 lm 对标，不按 W |
| **光源光效** | lm/W | 裸光源光通量 ÷ 光源功率 | 只用于评价灯珠/模组，**不能当整灯指标** |
| **灯具效能** | lm/W | 整灯光通量 ÷ 整灯输入功率（含驱动） | 评价整灯能效的**正确指标** |
| **灯具效率** | % | 灯具出射光通量 ÷ 内部光源总光通量 | 评价光学系统（反光杯/扩散板/格栅）的光损失 |
| **光强** | I，cd | 某方向上的发光强度 | 射灯、投光灯、探照灯的核心指标 |
| **中心光强** | cd | 光束中心的最大光强 | 判断「打得远不远、亮不亮」 |
| **照度** | E，lx | 单位面积接收到的光通量 | 设计/验收的核心指标（工作面照度） |
| **亮度** | L，cd/m² | 单位面积/单位立体角的光强 | 眩光、发光面舒适度的核心指标 |
| **配光曲线** | — | 光强随空间方向的分布 | 判断光斑形状、均匀度、眩光；要 IES/LDT 文件 |
| **光束角** | ° | 光强降到 50% 峰值的夹角 | 射灯选型的关键；≠ 光斑角 |
| **遮光角** | ° | 人眼看不到光源的临界角 | 防眩设计；深防眩筒灯的关键 |
| **UGR** | — | 统一眩光值，评价室内不舒适眩光 | 办公 ≤19，教室 ≤19（地方可更严） |
| **GR** | — | 眩光值，用于室外/体育 | 室外照明眩光评价 |
| **照度均匀度** | U0 = Emin/Eav | 最小照度 ÷ 平均照度 | 办公 ≥0.6，教室课桌面 ≥0.7 |
| **LPD** | W/m² | 照明功率密度 | 节能强制指标，按房间类型限值 |
| **距高比** | SHR | 灯具间距 ÷ 安装高度 | 判断布灯密度是否合理 |

> **关键区分**：**光通量（lm）决定「有多少光」，配光决定「光去哪」，照度（lx）决定「到工作面有多少」，亮度（cd/m²）决定「人眼看起来刺不刺」。** 四个概念不能混。

### L3 色度层（颜色对不对）

| 参数 | 含义 | 典型要求 | 注意 |
|---|---|---|---|
| **相关色温 CCT** | 光的「冷暖」，单位 K | 办公 3300–5300 K；商业 2700–4000 K；教室 3300–5300 K | 同一空间色温要统一；混用会显脏 |
| **一般显色指数 Ra** | CIE 13.3 的 8 个色样平均显色 | 一般 ≥80；商业/医疗 ≥90 | 对 LED 有局限，**必须搭配 R9** |
| **特殊显色指数 R9** | 饱和红色显色能力 | 商业/生鲜/医疗 R9 > 0，最好 ≥50 | Ra 高但 R9 负值是常见问题 |
| **色保真度 Rf** | CIE 224:2017 / TM-30 的 99 色样保真度 | 高端商业 Rf ≥90 | 与 Ra 不能直接换算 |
| **色域指数 Rg** | 平均饱和度偏移 | 100 为中性；>100 更艳，<100 更淡 | Rf 高 + Rg 接近 100 通常更自然 |
| **色容差 SDCM** | 与目标色坐标的偏差（麦克亚当椭圆） | 一般 ≤5；高端 ≤3 | 批次色差的主要指标 |
| **色度一致性** | 不同角度/不同灯具间的色差 | 见 GB/T 31831-2025 | 多灯拼接、洗墙时特别明显 |
| **光谱功率分布 SPD** | 各波长的辐射功率 | — | 判断蓝光峰值、荧光粉质量、光谱连续性 |
| **色漂移** | 老化后的色坐标变化 | 见 LM-80 / TM-21 / GB/T 31831 | 长期使用后发黄/发绿 |

> **产品经理必记**：**Ra 高 ≠ 颜色好。** 对 LED，至少同时看 **Ra + R9 + SDCM**；高端项目再加 **Rf/Rg**。CIE 明确表示 Rf 目前不能取代 Ra 用于法规/评级，但可以作为补充。

### L4 时间稳定层（稳不稳、久不久）

| 参数 | 含义 | 典型要求 | 注意 |
|---|---|---|---|
| **频闪波动深度** | 光输出最大值/最小值的调制程度 | 越低越好；GB 40070 按频率限值 | 低频大幅波动最伤眼 |
| **PstLM** | 短时闪变指数（0.05–80 Hz） | ≤1（EU 法规；教室修订稿） | 评价「看得见的闪烁」 |
| **SVM** | 频闪效应可视度（80 Hz–2 kHz） | ≤0.9（EU 法规）；NEMA 77 建议 ≤1.6 | 评价「频闪效应/转子效应」 |
| **启动时间** | 通电到规定光输出的时间 | 通常 <0.5 s；应急灯有专门要求 | 低温启动是难点 |
| **调光范围** | 可调的最低/最高光输出 | 1%–100% 常见；0.1% 高端 | 低亮度闪烁、关不死是常见问题 |
| **调光曲线** | 亮度随控制信号的变化 | 线性/对数/方根 | 人眼对低亮度更敏感，线性调光体验差 |
| **流明维持 L70/L80/L90** | 光通量降到初始值 70%/80%/90% 的时间 | 商用常见 L70 ≥50,000 h；L80 ≥50,000 h | 必须看测试条件（温度/电流） |
| **B 值** | 低于 L 值的产品比例 | L80/B50 常见 | B50 表示 50% 样品低于该值 |
| **开关循环寿命** | 可承受的开关次数 | 见产品规格 | 频繁感应场景要关注 |
| **应急响应/持续时间** | 断电后点亮时间/维持时间 | GB 51309：0.25 s/5 s；0.5–1.5 h | 按建筑类型和高度定 |

> **寿命的正确读法**：`L70 = 50,000 h` 只说明「平均光通量降到 70% 的时间」，不说明「50,000 h 后灯不坏」。还要看 **B 值、测试温度、驱动寿命、质保条款**。TM-21 的 6× 外推规则也意味着：LM-80 只测 6,000 h，最多只能报 36,000 h。

### L5 电气与能效层（省不省、兼容不兼容）

| 参数 | 含义 | 典型要求 | 注意 |
|---|---|---|---|
| **输入功率** | 整灯实际消耗功率 | 与标称偏差通常 ≤±10% | 虚标功率是常见问题 |
| **功率因数 PF** | 有功功率 ÷ 视在功率 | 商用 ≥0.9；大功率 ≥0.95 | 低 PF 会被甲方/电网考核 |
| **谐波 THD** | 电流波形畸变 | 见 GB 17625.1（C 类限值） | 便宜驱动常超标 |
| **驱动效率** | 输出功率 ÷ 输入功率 | 通常 85%–92% | 影响整灯效能和发热 |
| **待机功耗** | 关灯/待机时的功耗 | 越低越好；智能灯要关注 | 大规模部署时是隐性成本 |
| **浪涌抗扰度** | 抗雷击/电网浪涌能力 | 户外常见 2–6 kV | 道路/户外灯具必看 |
| **输入电压范围** | 正常工作电压 | 如 176–264 V | 电网波动大的地区要宽压 |
| **漏电流** | 对地泄漏电流 | 安规限值 | 金属外壳、Y 电容设计相关 |
| **调光兼容性** | 与调光器/系统的匹配 | 见协议表 | 「支持调光」≠「与你的调光器兼容」 |
| **绝缘电阻/耐压** | 绝缘性能 | 安规要求 | 量产抽检项 |

---

### L6 环境与可靠层（耐不耐用）

| 参数 | 含义 | 典型要求 | 注意 |
|---|---|---|---|
| **工作温度** | 允许的环境温度范围 | 室内 −10~40 °C；户外 −20~50 °C；工业更宽 | 实际结温远高于环境温度 |
| **存储温度** | 非工作状态温度 | 通常更宽 | 运输/仓储 |
| **湿度** | 允许相对湿度 | 如 10%–90% RH | 高湿+盐雾加速腐蚀 |
| **IP 等级** | 防尘防水 | 室内 IP20；户外 IP65/66；水下 IP67/68 | 看测试报告，不只看标称 |
| **IK 等级** | 抗冲击 | 户外/工业 IK08；更高 IK10 | 玻璃/塑料罩要关注 |
| **盐雾** | 抗盐雾腐蚀 | 沿海项目常要求 500 h+ | 铝材表面处理、螺丝材质 |
| **振动/跌落** | 抗运输/使用冲击 | 按产品类型 | 工矿、车载、便携设备 |
| **防腐/防化学** | 抗酸碱/溶剂 | 化工、医疗消毒环境 | 材料兼容性 |
| **寿命/失效率** | 整灯寿命、失效率 | 见 L4 | 驱动往往是短板 |
| **质保** | 保修年限与条款 | 家用 1–3 年；工程 3–5 年 | 看清是否含光衰、是否只换不修 |

---

### L7 体验与商业层（好不好用、卖不卖得动）

| 参数 | 含义 | 为什么重要 |
|---|---|---|
| **外观/工业设计** | 造型、颜色、质感、细节 | 家用/商业零售的决定性因素 |
| **安装便利性** | 开孔、接线、固定、调试 | 工程安装成本的大头 |
| **维护便利性** | 是否可换光源/驱动、是否需整灯拆 | 影响全生命周期成本 |
| **智能体验** | 配网、调光平滑度、场景、语音 | 家用/高端商业 |
| **包装与说明** | 防护、安装图、警示 | 减少售后和安装事故 |
| **成本** | BOM、认证、物流、安装 | 工程项目的生死线 |
| **交期与产能** | 打样、量产、备货 | 项目制企业的核心竞争力 |
| **品牌与案例** | 参考项目、检测报告 | 工程投标的门槛 |
| **售后与响应** | 质保、备件、失效分析 | 长期客户关系 |

## 3. 参数之间的「跷跷板」：没有全能灯

产品经理最重要的能力之一，是知道**提升一个指标会牺牲什么**。

| 你想要 | 通常会牺牲 | 原因 |
|---|---|---|
| **更高光效** | 显色性 / 成本 | 高显色荧光粉和滤光会降低转换效率 |
| **更高显色** | 光效 | R9/Rf 提升需要更宽光谱，效率下降 |
| **更低眩光（UGR）** | 灯具效率 / 光通量 | 防眩格栅、深藏光、扩散板都会挡光 |
| **更薄/更轻** | 散热 / 寿命 | 散热面积减小，结温升高 |
| **更高防护（IP）** | 散热 | 密封结构阻碍对流 |
| **更深调光** | 成本 / 低亮度稳定性 | 需要更好的驱动和更低纹波 |
| **更长寿命** | 成本 | 更好的芯片、驱动、散热、电容 |
| **更严格色容差** | 成本 / 交期 | 分 bin 更细，良率下降 |
| **更低成本** | 几乎一切 | 这是工程取舍的核心 |

> **给 PM 的话**：规格书不是「把所有参数拉到最高」，而是**在目标场景下找到最优组合**。一个 150 lm/W、Ra80、UGR19、3 年质保的办公面板灯，可能比 180 lm/W、Ra90、UGR16、5 年质保但贵 60% 的产品更适合项目。

**读法示例**：
- **办公**：L2 光度、L4 时间稳定、L5 电气能效都是 ●●●——所以 UGR、频闪、LPD、DALI 兼容性是重点。
- **医疗**：L3 色度和 L6 环境可靠是 ●●●——显色、洁净、消毒、可靠性优先。
- **道路**：L2、L4、L5、L6 全 ●●●——配光、寿命、光效、防护缺一不可。
- **家用**：L1 和 L7 是 ●●●——安全合规 + 好看好装，参数不必拉到工程级。

## 5. 怎么读一份灯具规格书

### 5.1 必查 12 项

| # | 查什么 | 合格的样子 | 危险信号 |
|---|---|---|---|
| 1 | 光通量 | 明确 lm，给测试条件 | 只写「相当于 xxW」 |
| 2 | 灯具效能 | 整灯 lm/W，含驱动 | 只给「光源光效」 |
| 3 | 配光 | 提供 IES/LDT 文件 | 只给光束角，无配光文件 |
| 4 | 显色 | Ra + R9（+ Rf/Rg） | 只给 Ra，不给 R9 |
| 5 | 色容差 | SDCM ≤3/5 | 完全不提 |
| 6 | 眩光 | UGR 值或遮光角 | 只写「防眩设计」 |
| 7 | 频闪 | 波动深度 / PstLM / SVM | 只写「无频闪」 |
| 8 | 寿命 | L70/L80 + B 值 + 测试条件 | 只写「50,000 小时」 |
| 9 | 驱动 | 品牌、PF、THD、效率、调光协议 | 只写「智能驱动」 |
| 10 | 防护 | IP/IK + 测试报告 | 只写 IP65，无报告 |
| 11 | 认证 | CCC/CQC/能效/CE 等 + 证书编号 | 只写「通过 3C」 |
| 12 | 质保 | 年限、范围、是否含光衰 | 条款模糊、只换不修 |

### 5.2 常见「参数注水」手法

| 手法 | 例子 | 破解 |
|---|---|---|
| **用光源光效冒充整灯效能** | 「180 lm/W」实际是灯珠数据 | 问「整灯输入功率多少？整灯光通量多少？」 |
| **用峰值/实验室数据** | 「最高 200 lm/W」 | 问「额定工况、25 °C、整灯实测」 |
| **只给最好看的显色** | 「Ra 95」但 R9 = −20 | 要求完整 R1–R15 或 Rf/Rg |
| **寿命不给条件** | 「50,000 h」 | 问「L70 还是 L80？B 值？环境温度？驱动寿命？」 |
| **IP 等级无报告** | 「IP66」 | 要求第三方 IP 测试报告 |
| **「无频闪」无定义** | 肉眼看不见≠无频闪 | 要求波动深度/PstLM/SVM 数据 |
| **「护眼」无标准** | 营销词 | 问「依据哪个标准？RG 等级？UGR？」 |
| **认证套用** | 证书覆盖型号与实际出货不符 | 核对证书型号、工厂、有效期 |

## 6. 参数怎么验证（测试方法概览）

| 参数 | 主要测试设备/方法 | 标准依据 |
|---|---|---|
| 光通量、光效、色度 | 积分球 + 光谱辐射计 | CIE S 025 / IES LM-79 |
| 配光、光强分布 | 分布光度计（转镜/转臂） | CIE S 025 / IES LM-79 |
| 照度、均匀度、UGR | 照度计 + 照明设计软件（DIALux/Relux） | GB/T 50034-2024 附录 |
| 频闪 | 频闪测试仪/示波器 + 光电探头 | CIE TN 006、IEC TR 61547-1、IEC TR 63158 |
| 流明维持 | LM-80 老化 + TM-21 外推 | IES LM-80 / TM-21 |
| 色漂移 | 老化前后光谱测试 | LM-80 / LM-84 |
| 结温/温升 | 热电偶、红外热像、电压法 | 产品标准/企业标准 |
| 电气安全 | 耐压仪、绝缘电阻仪、接地电阻仪 | GB/T 7000.1 |
| EMC | 骚扰/抗扰度测试系统 | GB/T 17743、GB 17625.1、GB/T 17626 |
| IP/IK | 防尘防水试验箱、冲击试验装置 | GB/T 4208、GB/T 20138 |
| 寿命/可靠性 | 老化房、高低温箱、振动台 | 企业标准/行业标准 |

> **PM 最该记住的一句**：**「没有测试条件的数据，等于没有数据。」** 任何参数，先问「在什么条件下测的、谁测的、报告在哪」。
