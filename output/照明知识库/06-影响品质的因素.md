# 06 影响品质的因素

> **回答的问题**：同样是 LED 灯，为什么有的用 1 年就坏，有的能用 5 年？品质到底由什么决定？
> **核心观点**：**品质是设计出来的，不是检出来的。** 检验只能守住下限，上限由设计、选型、供应链决定。

---

## 1. 先分清四个「品质」

很多争论源于把不同的「品质」混为一谈：

| 层次 | 定义 | 谁负责 | 怎么验证 |
|---|---|---|---|
| **合规品质** | 符合安全、EMC、能效等强制标准 | 设计+认证 | 证书/型式试验 |
| **性能品质** | 达到规格书的光、色、电、热指标 | 设计+选型 | 光电/热测试 |
| **一致性品质** | 批次之间、个体之间稳定一致 | 供应链+工艺+分 bin | 抽检/CPK |
| **体验品质** | 用户感知的眩光、频闪、调光、安装、维护 | 设计+人因 | 用户体验/现场反馈 |

> **一个产品可能「合规」但不「好用」，也可能「参数漂亮」但「批次翻车」。** 做产品经理，四个层次都要管。

## 3. 八大因素详解

### 3.1 光源（LED 芯片/封装）

| 影响点 | 具体表现 | 控制手段 |
|---|---|---|
| **芯片质量** | 光效、波长一致性、抗静电、抗老化 | 选品牌/等级；看 LM-80 数据 |
| **荧光粉** | 显色、色温、色漂移、光衰 | 配方与工艺；高温高湿老化验证 |
| **封装工艺** | 死灯、漏电、光衰、黄变 | 封装厂审计；回流焊兼容性 |
| **分 bin** | 批次色差、亮度差、电压差 | 明确 bin 范围；来料抽检 |
| **热阻** | 结温、寿命 | 选低热阻封装；散热设计 |
| **支架/基板** | 耐温、耐候、硫化 | 材料验证；含硫环境注意 |

**常见问题**：
- 用「白牌」芯片但标「国际大厂」→ 要求提供芯片批次/溯源
- 分 bin 太宽 → 同批灯颜色不一致
- 荧光粉耐热差 → 高温下色漂移、光衰

---

### 3.2 驱动电源

| 影响点 | 具体表现 | 控制手段 |
|---|---|---|
| **电解电容** | 寿命短板、鼓包、容量衰减 | 选耐高温长寿命电容；降额使用 |
| **驱动 IC** | 保护缺失、调光不稳 | 选成熟方案；异常测试 |
| **变压器/电感** | 异响、发热、效率 | 设计余量；浸漆/固定 |
| **散热** | 驱动温度高 → 寿命短 | 驱动位置、灌胶、散热片 |
| **保护功能** | 过压/过流/短路/过温失效 → 烧灯 | 逐项验证 |
| **输出纹波** | 频闪、光色不稳 | 纹波测试 |
| **调光兼容** | 低亮度闪烁、关不死 | 与目标调光器实测 |
| **灌封/三防** | 潮湿/盐雾环境失效 | 灌胶/三防漆 |

**一句话**：**LED 灯坏，驱动往往是第一嫌疑。** 选驱动要看品牌、方案、电容、保护、散热，不能只看价格。

---

### 3.3 光学系统

| 影响点 | 具体表现 | 控制手段 |
|---|---|---|
| **材料透光率** | 整灯效能低 | 选高透光材料；来料检测 |
| **黄变/老化** | 用久发黄、光衰 | 紫外/高温老化验证 |
| **配光设计** | 光斑不均、副光斑、黄斑 | 光学仿真 + 实测配光 |
| **防眩设计** | UGR 超标、刺眼 | 遮光角/格栅/深藏；UGR 模拟 |
| **色度一致性** | 不同角度色差、洗墙色带 | 光学设计 + 分 bin |
| **装配公差** | 漏光、偏心、光斑变形 | 公差分析 + 定位设计 |
| **积灰/清洁** | 光衰、外观差 | 防尘设计；易清洁表面 |

---

### 3.4 热管理

| 影响点 | 具体表现 | 控制手段 |
|---|---|---|
| **结温 Tj** | 光衰、色漂移、死灯 | 热仿真 + 实测；降额 |
| **热阻链** | 散热不足 | 低热阻封装、导热界面、散热器 |
| **环境温度** | 高温环境寿命骤降 | 按实际 Ta 设计；降额曲线 |
| **驱动发热** | 电容寿命短 | 驱动独立散热/远离热源 |
| **密封与散热矛盾** | IP 达标但热死 | 导热结构 + 呼吸阀/灌胶 |
| **热集中** | 局部光衰/黄斑 | 灯珠排布优化；均温 |

**关键公式**：

```
Tj ≈ Ta + P_heat × (Rjc + Rcs + Rsa)
P_heat ≈ P_in × (1 − η_电光转换)
```

> 结温每升高约 10 °C，寿命大致减半（Arrhenius 量级）。**散热设计必须按「最恶劣环境温度」算，不能按实验室 25 °C。**

---

### 3.5 结构与材料

| 影响点 | 具体表现 | 控制手段 |
|---|---|---|
| **密封结构** | 进水、起雾、失效 | 密封圈压缩量、防水接头、呼吸阀 |
| **材料耐候** | 黄变、开裂、粉化 | 紫外/盐雾/高低温验证 |
| **公差与装配** | 漏光、异响、装不上 | 公差分析、DFA |
| **承重/固定** | 掉落、变形 | 强度计算、吊装测试 |
| **阻燃** | 火灾风险 | 阻燃材料、灼热丝测试 |
| **表面处理** | 锈蚀、掉漆 | 盐雾测试、附着力测试 |
| **散热结构** | 结温高 | 散热面积、导热路径、风道 |

---

### 3.6 电气安全与连接

| 影响点 | 具体表现 | 控制手段 |
|---|---|---|
| **爬电距离/电气间隙** | 耐压失败、漏电 | 设计评审、安规预测试 |
| **绝缘** | 触电风险 | 绝缘材料、隔离设计 |
| **接地** | 外壳带电 | 接地连续性测试 |
| **端子/接线** | 过热、起火 | 额定电流匹配、压接质量 |
| **线缆** | 老化、短路 | 耐温/阻燃/线径 |
| **保险丝/保护** | 故障扩大 | 选型匹配、异常测试 |
| **浪涌** | 雷击损坏 | 压敏电阻/GDT/TVS |

---

### 3.7 工艺

| 影响点 | 具体表现 | 控制手段 |
|---|---|---|
| **SMT/回流焊** | 虚焊、立碑、灯珠损伤 | 钢网/温度曲线/首件 |
| **点胶/灌胶** | 气泡、溢胶、导热不良 | 工艺参数、真空脱泡 |
| **装配** | 漏装、错装、应力损伤 | 防呆设计、SOP、治具 |
| **老化（Burn-in）** | 早期失效流出 | 老化时间/条件 |
| **清洁** | 异物、短路、外观 | 清洁标准、环境控制 |
| **包装** | 运输损坏 | 跌落测试、包装设计 |

---

### 3.8 测试、供应链与设计

| 影响点 | 具体表现 | 控制手段 |
|---|---|---|
| **测试设备校准** | 数据不准 | 定期校准、比对 |
| **测试条件** | 数据不可比 | 统一温度/电压/稳定时间 |
| **抽检方案** | 漏检/误判 | AQL/抽样标准 |
| **来料一致性** | 批次差异 | IQC、二供、批次追溯 |
| **变更管理** | 偷换材料导致批量事故 | ECN、变更验证 |
| **设计余量** | 临界设计，环境一变就失效 | 降额设计、DFMEA |
| **标准符合性** | 认证失败/召回 | 合规矩阵、预测试 |

## 4. 设计阶段的 8 个关键决策

| 决策 | 选错会怎样 | 怎么选 |
|---|---|---|
| **光源方案** | 光效/显色/成本失衡 | 按场景权重选；看 LM-80 |
| **驱动方案** | 寿命短、频闪、认证不过 | 隔离/非隔离按结构；看电容/保护 |
| **光学方案** | 眩光、光斑差、效率低 | 仿真 + 实测；别只看报价 |
| **散热方案** | 光衰、死灯 | 按最恶劣 Ta 算；实测结温 |
| **结构方案** | 漏水、装不上、维护难 | 现场条件 + DFA |
| **材料方案** | 黄变、腐蚀、阻燃不过 | 环境测试 + 认证 |
| **降额策略** | 寿命短/成本高 | 电流/温度降额，找平衡 |
| **认证策略** | 上市延期 | 提前排期；型号覆盖 |

## 5. 品质验证体系

### 5.1 三道检验

| 环节 | 查什么 | 关键 |
|---|---|---|
| **IQC（来料）** | 灯珠、驱动、光学件、结构件、线材 | 分 bin、外观、尺寸、电气 |
| **IPQC（过程）** | SMT、装配、点胶、老化、测试 | 首件、巡检、关键工序 |
| **OQC（出货）** | 外观、光电、安规、包装 | 抽检、批次追溯 |

### 5.2 型式试验（Type Test）

- 光电性能（积分球/分布光度计）
- 安规（耐压/绝缘/接地/异常）
- EMC（骚扰/谐波/抗扰）
- 环境（高低温/湿热/温度循环/盐雾/IP/IK）
- 机械（振动/跌落/安装强度）
- 寿命（LM-80/TM-21 或整灯老化）

### 5.3 可靠性测试清单

| 测试 | 目的 | 典型条件（示例，按产品定） |
|---|---|---|
| **高温工作** | 散热/寿命 | 额定功率，Ta 上限，连续点亮 |
| **低温启动** | 低温可靠性 | −20/−40 °C 启动 |
| **湿热** | 防潮/绝缘 | 40 °C/93% RH |
| **温度循环** | 热胀冷缩/焊点 | −20~60 °C 循环 |
| **振动** | 运输/安装 | 按运输/使用谱 |
| **跌落** | 运输/便携 | 按包装/产品重量 |
| **盐雾** | 防腐 | 沿海项目 500 h+ |
| **开关循环** | 驱动/继电器 | 数万次 |
| **浪涌** | 雷击/电网 | 2–6 kV |
| **ESD** | 静电 | 接触/空气放电 |
| **IP** | 防尘防水 | 按标称等级 |
| **IK** | 抗冲击 | 按标称等级 |
| **光衰** | 寿命 | 老化 1,000–6,000 h + 外推 |

> 具体条件以产品标准、客户要求和目标市场法规为准；上表只是「测试菜单」。

## 6. 最常见的 6 个品质事故

| 事故 | 现象 | 根因 | 预防 |
|---|---|---|---|
| **批量光衰** | 用几个月明显变暗 | 散热不足/驱动电流偏大/灯珠质量差 | 热设计余量 + 降额 + LM-80 |
| **批量闪烁** | 低亮度闪、开关闪 | 驱动电容失效/调光不兼容/纹波大 | 驱动选型 + 调光实测 |
| **批次色差** | 同批灯颜色不一致 | 分 bin 太宽/混 bin/来料失控 | 明确 bin + IQC + 追溯 |
| **驱动烧毁** | 批量不亮/焦黑 | 散热差/浪涌/过载/电容鼓包 | 驱动散热 + 浪涌保护 + 异常测试 |
| **防水失效** | 进水/起雾/短路 | 密封圈压缩不足/接头未拧紧/呼吸阀失效 | IP 测试 + 装配防呆 |
| **耐压/漏电失败** | 认证不过/外壳带电 | 爬电距离不足/绝缘材料/接地不良 | 安规评审 + 预测试 |

## 7. 供应商管理：品质的另一半

| 动作 | 目的 |
|---|---|
| **供应商审核** | 看产线、设备、体系、实验室、客户案例 |
| **样品承认（PPAP 思路）** | 样品、规格、测试报告、BOM 锁定 |
| **来料检验（IQC）** | 批次一致性 |
| **二供开发** | 供应安全、议价能力 |
| **变更管理（ECN）** | 任何材料/工艺变更必须评估 |
| **批次追溯** | 出问题能定位 |
| **绩效评估** | 不良率、交期、响应 |

> **一句话**：**你无法检验出供应商的良心，只能通过审核、样品承认和变更管理把风险关进笼子。**

---

## 8. 品质成本：1-10-100 法则

> 这是质量管理中的一般经验法则，不是照明行业专用数据。

| 阶段 | 发现问题的成本 | 例子 |
|---|---|---|
| **设计阶段** | 1× | 改一个参数、改一张图 |
| **制造阶段** | 10× | 返工、报废、停线 |
| **售后阶段** | 100× | 召回、赔偿、品牌损失 |

**结论**：**在设计和样品阶段多花 1 块钱，胜过在售后花 100 块。** 这也是为什么 S3（规格书）和 S7（DVT）不能省。
