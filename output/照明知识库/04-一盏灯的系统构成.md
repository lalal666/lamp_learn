# 04 一盏灯的系统构成

> **回答的问题**：灯想要亮起来，到底由哪些部分构成？驱动电源、灯珠之外还有什么？
> **核心观点**：一盏 LED 灯是一个**微型光电热系统**，任何一块短板都会让整灯表现崩掉。

---

## 1. 一张系统框图

```
                          ┌──────────────────────────────────────────────┐
                          │                控 制 与 通 信                  │
                          │  开关 / 0-10V / DALI-2 / KNX / 无线 / 传感器   │
                          └──────────────────────┬───────────────────────┘
                                                 │ 调光/开关信号
                                                 ▼
┌────────┐   ┌──────────┐   ┌──────────┐   ┌──────────┐   ┌──────────┐   ┌────────┐
│ 市电/  │──▶│ EMI滤波  │──▶│ 整流+PFC │──▶│ DC-DC    │──▶│  LED     │──▶│ 光学   │──▶ 光
│ 电池/  │   │ 浪涌保护 │   │          │   │ 恒流驱动 │   │ 芯片/封装│   │ 透镜/  │
│ PoE    │   └──────────┘   └──────────┘   └────┬─────┘   └────┬─────┘   │ 反光杯/│
└────────┘                                      │              │         │ 扩散板 │
                                                │ 热             │ 热      └────────┘
                                                ▼              ▼
                                          ┌──────────────────────────┐
                                          │  热管理系统               │
                                          │  PCB / 导热界面 / 散热器  │
                                          └──────────────────────────┘

                          ┌──────────────────────────────────────────────┐
                          │  结构 / 电气安全 / 防护 / 应急辅助             │
                          │  外壳 / 密封 / 接线 / 接地 / 电池 / 标识       │
                          └──────────────────────────────────────────────┘
```

**一句话理解**：
- **电链**：市电 → 驱动 → LED，决定「能不能亮、稳不稳、调不调得动」。
- **光链**：LED → 光学 → 空间，决定「亮不亮、照到哪、晃不晃眼」。
- **热链**：LED/驱动 → 散热 → 环境，决定「活多久、衰多少」。
- **结构链**：外壳/密封/安装，决定「装不装得上、防不防水、安不安全」。

## 2. 模块一：光源（LED 芯片 → 封装 → 模组）

### 2.1 层级

| 层级 | 是什么 | 关键点 |
|---|---|---|
| **芯片（Die）** | 半导体发光单元 | 衬底（蓝宝石/SiC/硅）、外延质量、尺寸、波长、电压 |
| **封装（Package）** | 芯片+荧光粉+支架/基板+透镜 | SMD（2835/3030/5050）、COB、CSP、灯丝、大功率陶瓷封装 |
| **模组（Module）** | 多颗封装+PCB+连接器 | 电压/电流/串并方式、尺寸标准化（如 Zhaga） |
| **灯具（Luminaire）** | 光源+驱动+光学+结构 | 整灯效能、配光、安规 |

### 2.2 关键参数

| 参数 | 说明 | 为什么重要 |
|---|---|---|
| **光效（lm/W）** | 芯片/封装的光通量÷功率 | 决定整灯能效上限 |
| **正向电压 Vf / 电流 If** | 工作点 | 与驱动匹配；决定串并方案 |
| **色温/显色** | 荧光粉配方决定 | Ra、R9、Rf/Rg、SDCM |
| **分 bin** | 按电压/光通量/色温/显色分档 | 决定批次一致性；分 bin 越细越贵 |
| **热阻 Rth** | 结到焊点/基板的热阻 | 决定结温和寿命 |
| **最大结温 Tj** | 通常 105–150 °C（按器件） | 超过则光衰加速、失效 |
| **LM-80 数据** | 流明维持测试 | 寿命预测的基础 |

### 2.3 常见光源形态

| 形态 | 特点 | 典型应用 |
|---|---|---|
| **SMD** | 单颗贴片，灵活布板 | 面板灯、筒灯、灯带、球泡 |
| **COB** | 多芯片集成，光密度高、光斑均匀 | 射灯、工矿灯、投光灯 |
| **CSP** | 无支架、小尺寸、高密度 | 高密度面板、手机闪光灯、车灯 |
| **灯丝** | 仿钨丝外观，360° 发光 | 装饰灯、复古灯 |
| **大功率陶瓷** | 高可靠、耐高温 | 路灯、投光灯、工矿灯 |
| **LED 模组** | 标准化接口（Zhaga 等） | 可互换、可维护的工程灯具 |

> **产品经理视角**：不要只问「用的是哪家芯片」，要问「**哪个封装厂、什么 bin、什么价位**」。同一颗芯片，不同封装厂、不同分 bin，价格和一致性差很多。

## 3. 模块二：驱动电源（LED Driver）

### 3.1 驱动是干什么的？

LED 是**电流驱动**器件，不能直接接市电。驱动要做四件事：

1. **整流**：交流 → 直流
2. **功率因数校正（PFC）**：让电流波形跟随电压，满足谐波要求
3. **恒流/恒压输出**：给 LED 稳定的电流
4. **保护与控制**：过压、过流、短路、过温、调光、浪涌

### 3.2 常见拓扑

| 拓扑 | 特点 | 典型应用 |
|---|---|---|
| **非隔离 Buck** | 成本低、效率高、体积小 | 面板灯、筒灯、灯带（人手不可触及） |
| **非隔离 Boost** | 升压 | 多串 LED |
| **隔离 Flyback** | 安全隔离、适合高功率 | 工矿灯、路灯、外置驱动 |
| **LLC 谐振** | 高效率、大功率 | 大功率工矿灯/路灯 |
| **线性驱动（IC）** | 极简、无 EMI、效率低 | 小功率、低成本 |
| **恒压+恒流模块** | 恒压电源+DC-DC | 灯带、模组化 |

### 3.3 隔离 vs 非隔离

| 维度 | 隔离驱动 | 非隔离驱动 |
|---|---|---|
| **安全性** | 输出与市电隔离，触摸安全 | 输出带市电电位，结构必须保证不可触及 |
| **成本** | 较高 | 较低 |
| **效率** | 略低 | 略高 |
| **体积** | 较大 | 较小 |
| **适用** | 金属外壳、可触及、高功率、户外 | 双重绝缘/不可触及结构、小功率 |

> **合规提醒**：非隔离方案不是「不安全」，而是**必须靠结构保证不可触及**。如果外壳是金属且可能被触摸，通常需要隔离或加强绝缘。

### 3.4 驱动的关键参数

| 参数 | 典型要求 | 说明 |
|---|---|---|
| **输入电压** | 176–264 V（宽压） | 电网波动地区要更宽 |
| **输出电流/电压** | 与 LED 串并匹配 | 电流精度通常 ±3%–±5% |
| **功率因数 PF** | 商用 ≥0.9；大功率 ≥0.95 | 甲方/电网考核 |
| **谐波 THD** | 满足 GB 17625.1 C 类 | 便宜驱动常超标 |
| **效率** | 85%–92% | 影响整灯效能和发热 |
| **输出纹波** | 越低越好 | 纹波大 → 频闪、光色不稳 |
| **调光** | 0-10V / DALI-2 / PWM / 无线 | 注意调光深度和低亮度稳定性 |
| **保护** | OVP/OCP/SCP/OTP/浪涌 | 户外必看浪涌 |
| **隔离耐压** | 按安规 | 隔离型关键 |
| **寿命** | 电解电容是短板 | 高温环境寿命骤降 |
| **认证** | CCC/CQC/CE/UL | 与整灯认证绑定 |

### 3.5 驱动常见失效

| 现象 | 可能原因 |
|---|---|
| 灯闪/频闪 | 输出电容失效、纹波大、调光不兼容、PFC 不稳 |
| 灯不亮 | 驱动保护、LED 开路/短路、启动失败 |
| 低亮度闪烁/关不死 | 调光曲线/最小占空比/漏电流 |
| 驱动烧毁 | 散热不足、浪涌、输出过载、电容鼓包 |
| 批次性光衰 | 驱动电流偏大、散热不足 |

> **一句话**：**LED 灯坏，十有八九先坏驱动。** 选灯先选驱动，不是先选灯珠。

## 4. 模块三：光学系统

### 4.1 一次光学 vs 二次光学

| 层级 | 位置 | 作用 | 典型元件 |
|---|---|---|---|
| **一次光学** | 封装内部 | 芯片出光提取、初步配光 | 封装透镜、荧光粉层 |
| **二次光学** | 灯具内部 | 配光、防眩、均匀度 | 透镜、反光杯、扩散板、导光板、棱晶板、格栅 |

### 4.2 常见光学元件

| 元件 | 材料 | 作用 | 注意 |
|---|---|---|---|
| **TIR 透镜** | PMMA/PC/硅胶 | 精确配光、高光强 | 设计不良会有副光斑/黄斑 |
| **反光杯** | PC（镀铝）/铝 | 聚光、提高中心光强 | 镀层脱落、耐温 |
| **扩散板** | PS/PMMA/PC | 柔化光线、均匀出光 | 透光率损失、黄变 |
| **导光板** | PMMA | 侧入式面光源 | 网点设计、亮度均匀性 |
| **棱晶板** | PMMA/PC | 防眩、控光 | 效率损失 |
| **防眩格栅** | PC/铝 | 遮挡大角度光线、降低 UGR | 损失光效、积灰 |
| **遮光罩/深藏** | 铝/PC | 深防眩 | 需要空间 |
| **反射纸/白漆** | — | 提高光利用率 | 耐温、黄变 |

### 4.3 关键指标

| 指标 | 含义 | 影响 |
|---|---|---|
| **透光率** | 光学材料通过的光比例 | 直接决定灯具效率 |
| **配光曲线** | 光强空间分布 | 决定光斑、均匀度、眩光 |
| **光束角** | 50% 峰值夹角 | 决定「打多远、铺多宽」 |
| **遮光角** | 看不到光源的临界角 | 决定防眩水平 |
| **UGR** | 统一眩光值 | 室内舒适度 |
| **均匀度** | 工作面明暗差异 | 视觉舒适、验收指标 |
| **色度一致性** | 不同角度/位置的色差 | 洗墙、拼接时明显 |

> **产品经理视角**：光学是「最容易被低估」的模块。同样的灯珠和驱动，换个透镜/扩散板，整灯效能可能差 10%–20%，眩光差一个等级。

## 5. 模块四：热管理

### 5.1 为什么热是第一性约束

LED 的电光转换效率不是 100%。**输入功率中相当一部分变成热**（具体比例随器件和工况变化）。这些热必须从 **芯片结（Tj）** 一路传到 **环境（Ta）**：

```
Tj ──Rjc──▶ Tc（壳/焊点）──Rcs──▶ Ts（散热器）──Rsa──▶ Ta（环境）
```

- **Tj**：结温，最关键的寿命/光效变量
- **Rjc**：结到壳热阻（器件参数）
- **Rcs**：壳到散热器（导热界面材料）
- **Rsa**：散热器到环境（散热器设计）
- **Ta**：环境温度

**估算公式**：

```
Tj ≈ Ta + P_heat × (Rjc + Rcs + Rsa)
P_heat ≈ P_in × (1 − η_电光转换)
```

> 这是工程估算，实际需热仿真 + 实测。**结温每升高约 10 °C，寿命大致减半**（Arrhenius 量级规律，具体因器件而异）。

### 5.2 散热手段

| 手段 | 说明 | 适用 |
|---|---|---|
| **铝挤散热器** | 成本低、散热面积大 | 工矿灯、投光灯、线条灯 |
| **压铸铝外壳** | 结构+散热一体 | 筒灯、射灯、路灯 |
| **冲压/旋压** | 薄、轻、成本低 | 面板灯背板、球泡 |
| **热管/均温板** | 高效导热 | 高功率、小体积 |
| **导热硅脂/垫片** | 降低 Rcs | 所有 LED 与散热器界面 |
| **石墨/导热膜** | 面内导热 | 薄型产品 |
| **风扇/主动散热** | 强制对流 | 高功率、舞台、投影 |
| **结构风道** | 自然对流优化 | 户外灯具 |

### 5.3 热设计常见错误

| 错误 | 后果 |
|---|---|
| 散热器面积按「室温 25 °C」设计 | 实际 40–50 °C 环境，结温超标 |
| 忽略驱动发热 | 驱动电容寿命骤降 |
| 导热界面材料太厚/有气隙 | Rcs 增大，结温升高 |
| 密封结构无对流 | IP 达标但热死 |
| 灯珠排布过密 | 热集中，局部光衰 |
| 没有热仿真/实测 | 批量光衰、死灯 |

> **一句话**：**光效是「设计出来的」，寿命是「散热出来的」。**

## 6. 模块五：结构与机械

### 6.1 结构要解决的问题

| 问题 | 设计手段 |
|---|---|
| **安装** | 开孔尺寸、挂板、吊线、轨道、支架、磁吸 |
| **防护** | 密封圈、防水接头、呼吸阀、灌胶 |
| **散热** | 散热器、风道、导热路径 |
| **安全** | 防触电、爬电距离、接地、阻燃、防坠落 |
| **光学** | 遮光角、防眩、出光面 |
| **维护** | 可换光源/驱动、快拆、前维护 |
| **外观** | ID、材质、表面处理、颜色 |

### 6.2 常见材料

| 材料 | 特点 | 典型用途 |
|---|---|---|
| **压铸铝** | 散热好、强度高、成本中 | 筒灯、射灯、路灯、工矿灯 |
| **铝型材** | 散热好、可长尺寸 | 线条灯、面板灯边框 |
| **冲压钢/铁** | 便宜、强度高、重 | 支架灯、底盘 |
| **工程塑料（PC/ABS）** | 绝缘、轻、便宜 | 家用灯、面板灯、驱动外壳 |
| **PMMA/PC** | 透光、可做透镜/扩散板 | 光学件 |
| **硅胶** | 耐温、密封 | 密封圈、透镜 |
| **玻璃** | 耐候、透光、重 | 户外灯罩、装饰灯 |

### 6.3 结构常见失效

| 现象 | 原因 |
|---|---|
| 漏水/进水 | 密封圈压缩量不足、接头未拧紧、呼吸阀失效 |
| 漏光 | 拼接缝隙、公差、遮光设计不足 |
| 异响 | 热胀冷缩、卡扣松动 |
| 安装不上 | 开孔/吊装尺寸不兼容 |
| 外壳带电 | 绝缘/接地/爬电距离不足 |
| 塑料黄变/开裂 | 紫外、高温、材料选错 |

## 7. 模块六：电气安全与连接

| 项目 | 要求 | 说明 |
|---|---|---|
| **爬电距离/电气间隙** | 按电压、污染等级、材料组别 | 安规核心 |
| **绝缘** | 基本/附加/双重/加强绝缘 | 隔离型驱动关键 |
| **接地** | 金属外壳可靠接地 | 接地电阻、连续性 |
| **接线端子** | 额定电流/线径匹配 | 端子过热是常见故障 |
| **线缆** | 耐温、阻燃、线径 | 内部线/外部线 |
| **保险丝/断路器** | 过流保护 | 故障时防止起火 |
| **浪涌保护** | 压敏电阻/GDT/TVS | 户外/雷区 |
| **防触电** | 不可触及带电件 | 结构+绝缘配合 |

> **PM 提醒**：这些项目在样机阶段看不出来，但**认证和批量事故都出在这里**。一定要做安规预测试。

## 8. 模块七：控制与通信

| 方式 | 典型协议 | 特点 | 适用 |
|---|---|---|---|
| **开关** | — | 最简单 | 基础照明 |
| **模拟调光** | 0-10V / 1-10V | 便宜、无地址 | 办公、学校 |
| **数字可寻址** | DALI / DALI-2（IEC 62386） | 单灯地址、状态反馈、场景 | 商业/公建 |
| **楼宇总线** | KNX | 与 HVAC/遮阳/安防联动 | 高端公建 |
| **舞台/景观** | DMX512 | 高速、动态色彩 | 舞台、立面 |
| **无线** | Zigbee / BLE Mesh / Wi-Fi | 改造方便 | 家用、存量改造 |
| **IP 化** | PoE / Matter/Thread | 供电+控制一体、生态兼容 | 智能楼宇/家居 |
| **传感** | PIR/微波/光感/雷达 | 人来灯亮、恒照度 | 办公、车库、走廊 |

**选型要点**：
- 要**单灯控制/状态反馈/场景** → DALI-2
- 要**楼宇联动** → KNX（可经网关接 DALI）
- 要**简单调光/控成本** → 0-10V
- 要**无线改造** → Zigbee/BLE Mesh（注意跨品牌兼容）
- 要**动态色彩** → DMX512

> 协议细节与对比见 [01-灯具分类全景](01-灯具分类全景.md) 第 8 节。

## 10. 能量链：整灯效能是怎么被「吃掉」的

假设一款面板灯（**以下为示例，不是实测**）：

| 环节 | 效率/系数 | 累计效果 |
|---|---|---|
| LED 封装光效（额定工况） | 180 lm/W | 180 lm/W |
| 驱动效率 | 88% | 158 lm/W |
| 光学效率（扩散板+反射） | 85% | 134 lm/W |
| 热/其他损失 | 92% | 123 lm/W |
| **整灯效能** | — | **约 123 lm/W** |

**结论**：
- 标称「180 lm/W」如果是灯珠数据，整灯可能只有 120 lm/W 左右。
- **整灯效能 = 光源光效 × 驱动效率 × 光学效率 × 热损失系数**。
- 提升整灯效能，四个环节都要看，不能只换「更亮的灯珠」。

## 11. 系统级设计的「三个匹配」

### 11.1 光与电匹配

- LED 串并方式 ↔ 驱动输出电压/电流范围
- 驱动电流 ↔ 灯珠额定电流（降额使用更长寿）
- 调光方式 ↔ 驱动 IC 支持能力
- 输出纹波 ↔ 频闪要求

### 11.2 热与功率匹配

- 输入功率 ↔ 散热面积/热阻
- 环境温度 ↔ 降额曲线
- 驱动发热 ↔ 驱动位置/散热
- 密封等级 ↔ 对流散热能力

### 11.3 结构与安装匹配

- 开孔尺寸 ↔ 现场吊顶
- 承重/吊装 ↔ 建筑结构
- 维护方式 ↔ 是否可前维护/可换驱动
- 防护等级 ↔ 安装位置（室内/半户外/户外/水下）

> **一句话**：**灯不是「堆料」，是「匹配」。** 每个模块单看都不错，匹配不好整灯就翻车。

## 12. 成本大致分布（量级参考）

> 以下为行业常见量级，**不同产品差异极大**，仅用于建立成本意识，不可用于报价。

| 模块 | 大致占比 | 说明 |
|---|---|---|
| LED 光源（芯片/封装/模组） | 20%–35% | 芯片品牌、分 bin 影响大 |
| 驱动电源 | 15%–25% | 隔离/非隔离、调光、品牌影响大 |
| 结构/散热（铝材/压铸/塑料） | 20%–30% | 铝价、模具摊销影响大 |
| 光学件（透镜/扩散板/反光杯） | 10%–20% | 材料、精度影响大 |
| 装配/测试/认证/包装/物流 | 10%–20% | 认证和测试是隐性成本 |

**降本的正确顺序**：
1. 设计优化（减少零件、简化装配）
2. 供应链议价/二供
3. 材料替代（在可靠性允许范围内）
4. 分 bin 放宽（会牺牲一致性）
5. 最后才是「换便宜驱动/灯珠」（风险最高）
