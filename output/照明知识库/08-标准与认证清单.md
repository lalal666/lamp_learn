# 08 标准与认证清单

> **回答的问题**：做一盏灯，到底要符合哪些标准？要拿哪些认证？各自管什么？
> **使用方式**：按「安全 → 性能 → 设计 → 能效 → 专项 → 国际 → 认证」顺序查。
> **时效声明**：截至 **2026-11-01**。标准会换版，**设计冻结/投标/认证前必须到官方平台复核**。

---

## 0. 先建立三层认知

| 层次 | 标准类型 | 回答什么问题 | 例子 |
|---|---|---|---|
| **产品层** | 安全、性能、能效 | 这盏灯本身合不合格、好不好 | GB/T 7000.1、GB/T 31831、GB 30255 |
| **设计层** | 建筑照明设计标准 | 这个空间该用多少光、什么光 | GB/T 50034、GB 55015 |
| **专项层** | 行业/场景标准 | 这个特殊场景有什么额外要求 | GB 51309、GB 7793、GB/T 3836 |

> **常见错误**：拿「设计标准」当「产品标准」，或拿「产品标准」当「设计标准」。两者不能互相替代。

## 3. 性能与应用标准

| 标准 | 名称/管什么 | 状态/备注 |
|---|---|---|
| **GB/T 31831-2025** | LED 室内照明应用技术要求 | ✅ 2026-04-01 实施，替代 GB/T 31831-2015；新增 PstLM/SVM、驱动分类、碳足迹 |
| **GB/T 9473-2022** | 读写作业台灯性能要求 | ✅ 2024-01-01 实施，替代 2017 版；A/AA 级、照度均匀度、频闪、蓝光 |
| **GB/T 24827-2026** | 道路与街路照明灯具性能规范 | ⚠ 新版，替代 2015 版；以实施日期为准 |
| **GB/T 24823 系列** | LED 模块性能要求 | ⚠ 按具体分册/版本 |
| **GB/T 24824** | 普通照明用 LED 模块测试方法 | ⚠ 按现行版本 |

> **产品经理注意**：性能标准里最常用的是 **GB/T 31831-2025**（室内 LED 应用）和 **GB/T 9473-2022**（台灯）。前者是「工程灯具的通用性能门槛」，后者是「台灯的产品标准」。

## 5. 能效标准

| 标准 | 名称 | 适用范围 | 状态 |
|---|---|---|---|
| **GB 30255-2019** | 室内照明用 LED 产品能效限定值及能效等级 | LED 筒灯、定向集成式 LED 灯、非定向自镇流 LED 灯 | ✅ 现行；**GB 30255-2026 将于 2027-09-01 实施** |
| **GB 38450-2019** | 普通照明用 LED 平板灯能效限定值及能效等级 | LED 平板灯（厚度 ≤85 mm） | ✅ 2021-01-01 实施 |
| **GB 37478-2019** | 道路和隧道照明用 LED 灯具能效限定值及能效等级 | **仅道路/隧道** LED 灯具 | ✅ 现行 |

### 5.1 三者的关系（最容易搞混）

```
室内 LED 产品
├── 筒灯 / 定向集成式 LED 灯 / 非定向自镇流 LED 灯 → GB 30255-2019
├── LED 平板灯（面板灯） → GB 38450-2019
└── 其他室内灯具 → 暂无专门能效强标，参考 GB/T 31831 / 客户要求

道路/隧道 LED 灯具 → GB 37478-2019
```

> **常见错误**：把 **GB 37478** 当成室内能效标准。它是**道路和隧道**专用，不适用于办公室面板灯。

### 5.2 能效标识

- 中国实行**能效标识**制度，列入目录的产品需备案并加施标识。
- 能效等级通常 1 级最高、3 级为市场准入（不同标准分级不同）。
- **能效标识 ≠ 光品质**：它主要考核能效，不全面考核眩光、频闪、显色。

## 8. 认证与测试报告清单

### 8.1 中国

| 认证/报告 | 性质 | 管什么 | 适用 |
|---|---|---|---|
| **CCC** | 强制 | 安全+EMC（目录内灯具） | 固定式/可移式/嵌入式灯具、LED 驱动等 |
| **CQC** | 自愿 | 安全/性能/蓝光等 | 项目加分、客户要求 |
| **中国能效标识** | 强制（目录内） | 能效等级 | GB 30255/38450/37478 覆盖产品 |
| **消防产品认证** | 强制 | 应急照明/疏散指示 | GB 17945 |
| **防爆合格证（Ex）** | 强制（防爆场景） | 防爆安全 | GB/T 3836 |
| **MA 煤安证** | 强制（煤矿） | 矿用安全 | 煤矿灯具 |
| **CCC 汽车** | 强制 | 汽车灯具安全/配光 | GB 4599 |
| **第三方检测报告** | 自愿/项目要求 | 光电/频闪/寿命/IP 等 | 招标/验收 |

**CCC 目录要点**（照明电器类）：
- 电源电压 **>36 V 且 ≤1000 V** 的**固定式、可移式、嵌入式**灯具
- 常见：固定式通用灯具、嵌入式灯具、可移式通用灯具、水族箱灯具、夜灯、地面嵌入式、儿童用可移式
- **电池供电的手电筒/可移式灯具**通常不在 CCC 灯具目录内（但电池安全另有要求）
- LED 模块用电子控制装置（驱动）也在目录内

> ⚠ 目录会调整，出货前核对最新版《强制性产品认证目录描述与界定表》。

### 8.2 国际

| 认证/报告 | 市场 | 管什么 |
|---|---|---|
| **CE（LVD/EMC/RoHS/ErP）** | 欧盟 | 安全/EMC/有害物质/能效 |
| **UKCA** | 英国 | 同 CE 范围 |
| **UL 1598 / UL 8750** | 北美 | 灯具安全 / LED 驱动安全 |
| **ETL** | 北美 | 与 UL 等效的 NRTL 认证 |
| **ENEC** | 欧洲 | 灯具安全 |
| **DLC** | 北美 | 能效/光品质（补贴资格） |
| **ENERGY STAR** | 北美 | 能效 |
| **E-mark** | 欧洲/出口 | 汽车灯具法规 |
| **IP/IK 报告** | 全球 | 防护等级 |
| **LM-79/LM-80/TM-21 报告** | 全球 | 光电/寿命数据 |

> **认证 ≠ 测试报告**：CCC 是市场准入；LM-79 是测试方法/报告；DLC 是能效名录。三者不能互相替代。

## 9. 标准怎么用：一张映射表模板

做项目时，建议把每个需求映射到「标准 → 参数 → 测试 → 证据」：

| 需求 | 标准/条款 | 参数 | 测试方法 | 验收证据 |
|---|---|---|---|---|
| 办公室够亮 | GB/T 50034-2024 第 5.3 节 | 300 lx | 照度计/DIALux | 照明计算书/现场实测 |
| 不刺眼 | GB/T 50034-2024 | UGR≤19 | 软件计算 | UGR 报告 |
| 颜色真实 | GB/T 50034 / GB/T 31831 | Ra≥80、R9>0 | 积分球/光谱仪 | 检测报告 |
| 不频闪 | GB/T 31831-2025 / GB 40070 | PstLM/SVM/波动深度 | 频闪测试仪 | 检测报告 |
| 安全 | GB/T 7000.1-2023 | 耐压/绝缘/接地 | 安规测试 | CCC/CQC 报告 |
| 蓝光安全 | GB/T 20145 / GB/Z 39942 | RG0/RG1 | 光生物安全测试 | 报告 |
| 能效达标 | GB 30255/38450 | 能效等级 | 能效测试 | 能效标识/报告 |
| 寿命 | IES LM-80/TM-21 | L70/L80、B 值 | 老化+外推 | LM-80/TM-21 报告 |
| 户外防护 | GB/T 4208 | IP65/66 | IP 测试 | 第三方报告 |
| 应急 | GB 51309-2018 | 响应/持续时间 | 系统测试 | 消防认证/验收 |

## 10. 最容易搞错的 8 件事

| # | 错误认知 | 正确认知 |
|---|---|---|
| 1 | GB 37478 是室内 LED 能效标准 | 它是**道路/隧道**专用；室内看 GB 30255 / GB 38450 |
| 2 | GB/T 50034 是产品标准 | 它是**设计标准**，管空间怎么设计，不管单个产品合格 |
| 3 | CCC 认证 = 光品质好 | CCC 主要管**安全/EMC**，不保证显色/眩光/频闪 |
| 4 | 还在用 GB/T 31831-2015 | 已被 **GB/T 31831-2025** 替代（2026-04-01 实施） |
| 5 | 还在用 GB 7000.1-2015 | 已被 **GB/T 7000.1-2023** 替代（2026-01-01 实施） |
| 6 | 蓝光危害按 GB 7000.1 判 RG0 | 新版已删除该条款；按 **GB/T 20145 / GB/Z 39942** |
| 7 | IEC TR 62778 是现行依据 | IEC 已于 2023 年撤销；国内用 **GB/Z 39942-2021** |
| 8 | 能效标识 = 全性能认证 | 它主要考核**能效**，不覆盖眩光/频闪/显色/寿命 |
